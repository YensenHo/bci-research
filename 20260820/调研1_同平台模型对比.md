## (a) 会议纪要三个声明的核实结论

### 1. 「DeepSleepNet：2500 参数、量化 <50KB、推理 <0.5ms、准确率 72–75%」 → ❌ 误记（张冠李戴）

- **真实 DeepSleepNet** = Supratak et al. 2017《DeepSleepNet: A Model for Automatic Sleep Stage Scoring Based on Raw Single-Channel EEG》，IEEE TNSRE，DOI `10.1109/TNSRE.2017.2721116`，arXiv `1703.04046`。
- 它是 **睡眠分期** 模型（不是运动想象解码），架构 = **双分支 CNN + 双向 LSTM**，参数量 **百万级（约 110 万）**，单通道 EEG 输入。和「2500 参数 / <50KB / <0.5ms / 72–75%」完全不沾边。
- 确实存在一个轻量版 **DeepSleepNet-Lite**（arXiv `2108.10600`，TNSRE 2021，DOI `10.1109/TNSRE.2021.3117970`）：只处理 90s 单通道输入、加了 Monte-Carlo dropout，但**仍是睡眠分期、参数量仍远超 2500**。
- **会议纪要里「2500 参数 / 量化 <50KB / 推理 <0.5ms / 72–75%」这个画像，实际对应的是量化后的 EEGNet 类模型**——本项目 EEGNet 约 1.7K 参数、INT8 量化 <50KB，Q-EEGNet 8bit（arXiv `2004.11690`）也是数千参数级、0.6mJ/次。结论：**名字和数值都被记串了**。

### 2. 「LeafNet：脉冲神经元替代激活、<100 参数、人体通信带宽占用 0.8%」 → ❌ 查无公开出处

- arXiv / GitHub / OpenAlex 均**不存在**叫 LeafNet 的「脉冲 EEG」模型。arXiv 上仅有的两个 LeafNet 是：植物叶片分类 `SWP-LeafNET`（arXiv `2009.05139`）和视觉语言模型 `LeafNet`（arXiv `2602.13662`），与脑电无关。
- 「脉冲/SNN + EEG 端侧」这一方向**确实真实存在**，有可追溯的工作（见下表）：`2307.08501`（CNN-SNN 混合听觉注意力）、`2410.16613`（癫痫 SNN on Xylo 神经形态芯片）、`2402.09424`（SNN 癫痫检测）、`2601.00020`（铁电突触个性化 SNN）——但**没有任何一篇叫 LeafNet、也没有 <100 参数的记录**。
- 「人体通信带宽占用 0.8%」无可检索出处，判定为误记/口误。

### 3. 「1gNet：准确率 72–75%」 → ❌ 查无公开出处

- arXiv / GitHub / OpenAlex 均无名为 **1gNet** 的 EEG 解码模型（OpenAlex 只返回无关的生物医学论文）。
- 「72–75%」这个区间恰好落在 EEGNet 在 Physionet MI 的 3/4 类准确率（**75.07% / 65.07%**，arXiv `2004.00077`）附近，**很可能是对 EEGNet（或其缩放版）的误记**。

## (d) 关于「RV1106 / 国产 NPU 上跑 EEG 神经解码」的先例核查

**结论：公开可检索范围内，未找到任何在 RV1106 / RV1103 / Rockchip NPU 上做 EEG 神经解码（运动想象等）的公开论文或 GitHub 仓库。**
- GitHub 搜索 `rv1106 eeg`、`rockchip eeg`、`rknn bci`、`eeg rknn`、`rv1103 eeg` 均**零结果**（非空集合，是真没有）。
- Rockchip 官方 `rknn_model_zoo` 只收录视觉模型（YOLO、MobileNet、分类/检测/分割），无任何脑电/生理信号模型。
- 国际上的 EEG 端侧部署集中在 **ARM Cortex-M4/M7 与 RISC-V（PULP Mr.Wolf / GAP8 / GAP9）**，未见国产 RKNN NPU 路线的 EEG 解码先例。

## (e) 一句话结论

**本项目 EEGNet 76.39% @ RV1106（Cortex-A7 CPU 18.5ms、参数量 ~1.7K）在「精度-参数量-端侧速度」上已与 ETH PULP/GAP9 一脉的国际一流端侧 EEGNet 部署（2 类 ~82%@Physionet、5.8–15ms、µJ–mJ 级）处于同一数量级，且是公开可检索范围内在 Rockchip RV1106 国产 NPU 上跑通 EEG 神经解码的首个案例——但注意两点：① 精度绝对值不可与 Physionet MI（109 被试）直接对比，本项目 76.39% 是 BCIC IV 2a（9 被试）二分类；② 其 NPU 1.2ms/15× 加速真实、但 INT8 量化精度不达标（argmax 一致率 42–58%），与文献中 Q-EEGNet 8bit 仅损失 0.4% 形成鲜明反差，说明短板不在模型而在 RV1106 的 INT8 量化工具链对深度可分离小模型的支持不足。
