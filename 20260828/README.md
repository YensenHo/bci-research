## 二、三大核心发现（本轮最重要的三个结论）

### 🔥 发现 1：NPU 量化崩坏 = RKNN 工具链 bug，不是量化极限（P0-2）
- PyTorch fake-quant 标准 INT8 量化 argmax 一致率 **98.46%**，板载 NPU 实测 **42~58%**，差 40~56pp。
- 结论：问题不在模型量化方法（QAT/混合量化「无可救的对象」），在 RKNN 工具链对深度可分离小模型的实现（与既有「Gemm 量化 logits 偏移 −44」线索一致）。
- 工程结论：NPU 线维持关闭，解码写死 CPU。**这反过来强化「类脑换轨」——SNN 的 0/1 脉冲天然规避 INT8 量化。**

### 🔥 发现 2：噪声增强的收益在低 SNR 拐点区（P0-1a）
- 突发噪声增强 = null（与纯 AWGN 增强无差异，诚实负结果）。
- 但 AWGN 增强的鲁棒性优势**只在 8~14 dB 瀑布拐点区显现**：8dB 处基线崩到 66.36%，增强守住 70.30%（**+3.94pp**），**SNR 崩塌拐点后移 ≥3.4 dB**，恰好对齐板载 SNR 瀑布拐点。
- 一句话：约束驱动鲁棒解码的价值不是「提精度」，是「把解码失效的 SNR 边界往下推」。

### 🔥 发现 3：板载实测印证零损失（P0-3）
- 板载 McNemar（6480 配对）：直连 76.16% vs 经 HBC 76.17%，b=80/c=81，**p≈0.94（完全不显著）**。
- 对比旧基线（经 HBC 掉 0.62pp、p=0.0028 显著）→ 噪声增强模型经 HBC 链路**统计上不可分辨的零退化**，板上实测（非仿真）印证约束驱动鲁棒解码。

## 四、20260829 升级（芯片性能提升完整链路）

> 从「世界主流技术能否提高我们性能」出发的一整轮升级，全部板载实测。完整底稿见 `芯片能力全景_20260829.md`。

| 阶段 | 结果 |
|---|---|
| EEG-TCNet 移植（世界主流轻量模型） | 四分类 +5.56pp（56.87→62.42%），配置适配短窗（论文原配置反而 −1.9pp） |
| LIF 化（surrogate） | 零代价追平 ANN（TCN 架构也成立） |
| 四分类三环闭环 | 62.42% → 经 HBC 62.35%（McNemar p≈0.80） |
| HBC 噪声增强（约束驱动） | 8dB +14.85pp（54.17 vs 39.31%），clean 不降反升 |
| SNN 稀疏化 | 甜区 8~13%（8dB 反升 +1.77pp），脉冲流量 −43~71% |
| 真实 HBC 可行性 | PWM 100MHz/ADC 18kSPS/GPIO 9.98MHz 板载验证，¥30 方案就绪 |

**诚实负结果**（方法边界，均有实测）：欧氏对齐 0 增益（T/E 差异仅 1.45%）、通道剪枝 −3.6~−5.9pp（22ch 分布式编码无冗余）、输入脉冲编码 −24~−34pp（delta 量化信息瓶颈）。

**芯片最终状态**：四分类 63.58%（LIF-EEG-TCNet + HBC 增强），8dB 守住 54.17%，50.5ms，类脑脉冲规避 NPU bug，上位机可视化一键演示。

## 五、行动纲领（贯穿所有工作）

**「稀疏的脑信号 → 稀疏的类脑计算 → 稀疏的人体传输」** —— 三者共享稀疏性这一物理本质：
- SNN 的 0/1 脉冲 = HBC 要传的载荷（不用把浮点硬塞进窄信道）
- HBC 带宽约束 = 逼出 SNN（稀疏脉冲）
- SNN 0/1 脉冲 = 规避 NPU INT8 量化 bug（换轨）

Chip Demo 和创业都是这一个纲领的载体。每次交付前过 `03` 文档末尾的「纲领自检清单」。
