- 下载命令（断点续传）：
  ```bash
  curl -C - -O https://fb-ctrl-oss.s3.amazonaws.com/emg2qwerty/emg2qwerty-data-2021-08.tar.gz
  tar -xvzf emg2qwerty-data-2021-08.tar.gz
  ```
- 许可证：**CC-BY-NC-4.0**（非商用，研究用途可）。

### 1.2 大小（实测，非估算）

```
HTTP HEAD 返回（2026-08-28 实测）：
  HTTP/1.1 200 OK
  Content-Length: 308382645571   (≈ 287 GiB ≈ 308 GB，压缩 tar.gz)
  Last-Modified: 2021-08-24
```
- sEMG 为噪声型信号，几乎不可压缩 → 压缩包 ≈ 原始大小。
- 原始估算佐证：346 小时 × 3600s × 32ch × 2000Hz × 4B(float32) ≈ 3.2×10¹¹ B ≈ 318 GB，
  与 Content-Length 一致。
- **结论：287 GiB 远超 50GB 阈值，全量下载不现实。** S3 直链可达（GFW 未阻断），
  但官方是**单文件全量包**，**没有 30 被试子集/按用户分片的下载接口**；
  `metadata.csv`（含用户列表，可据此筛 30 人）也**打在这个 tar.gz 里**，无法单独低成本获取。

### 1.3 格式（依据官方 `emg2qwerty/data.py` 源码，逐字段核对）

- 共 **1136 个文件**：1135 个 session 文件 + 1 个 `metadata.csv`。
- 每个 session 一个 **HDF5** 文件，顶层 group 名 `emg2qwerty`。
- 核心数据集 `emg2qwerty/timeseries` 是 **compound dataset**，含三个字段：

  | 字段 | shape | 含义 |
  |---|---|---|
  | `emg_left`  | (T, 16) | 左手 16 通道 sEMG（**已高通滤波**） |
  | `emg_right` | (T, 16) | 右手 16 通道 sEMG（**已高通滤波**） |
  | `time`      | (T,)    | 绝对 unix 时间戳（秒，单调递增） |

- **采样率 2kHz**，每侧 16 电极，双侧 **32 通道**（官方源码 docstring 明确）。
- group attributes（元数据，很小，载入内存）：
  - `session_name` / `user` / `condition`（= `"on_keyboard"`）/ `duration_mins`
  - `keystrokes`：JSON 字符串 → `list[{"key": <pynput 键名>, "start": <按下时间>, "end": <抬起时间>}]`
  - `prompts`：JSON 字符串 → `list[{"payload": {"text": ...}, "start", "end"}]`
- 击键 `key` 用 pynput 表示：字母/数字/标点是字符（`'a'`、`'A'`、`'1'`、`','`），
  修饰键为 `Key.space` / `Key.shift` / `Key.enter` / `Key.backspace` 等。

### 1.4 规模

- 108 人 / 1135 会话 / 346 小时（官方 README）。MyoText 用 30 被试子集。

## 3. 预处理（`preprocess_emg.py`）

按 MyoText 描述实现击键切段：

1. 读 HDF5 `timeseries`，拼出 32ch EMG（`emg_left`‖`emg_right`）与时间戳。
2. 读 `keystrokes`（JSON），逐击键按 `start`（按下时间）切「**前 1s + 后 1s**」。
3. 用 `np.searchsorted` 定位采样点，片段固定长度 **T = 4000**（2s @ 2kHz），
   会话首尾越界用**零补齐**。
4. 键名归一化 → 8 指标签（`qwerty_mapping.LETTER_TO_FINGER`）：
   拇指（`Key.space`）/ 修饰键（shift/enter/backspace/tab）/ 数字与未覆盖符号 → 跳过。
5. 输出 `npz`：`X (N,1,32,4000)`、`y (N,)`、`finger_names`、`keys`（原始键名，便于核对）。
6. 可选 `--standardize` 逐通道标准化（默认关，忠实「原始分辨率」）。

自检（mock 会话，不依赖真实数据）已通过：8 指标签完整、空格键正确跳过、越界零补齐正确。

## 4. 手指分类 CNN（`finger_cnn.py`）

轻量全卷积 CNN，结构对齐 EEGNet（Lawhern 2018），**无循环、无注意力**（为类脑化让路）：

```
Block1: Conv2d(1,F1=8,(1,63)) → BN → DepthwiseConv2d(8,16,(32,1),groups=8)
        → BN → 激活 → AvgPool(1,4) → Dropout
Block2: SeparableConv2d(16,16,(1,15)) [depthwise + pointwise] → BN → 激活 → AvgPool(1,8) → Dropout
分类头: Flatten → Conv2d(1x1) → 8
```

- `n_channels=32`、`n_classes=8`、`input_length=4000` 均可配置。
- 时间卷积抓跨时间局部特征，depthwise (32,1) 把 32 个 sEMG 通道压成 1（同 EEGNet 压 22 电极）。
- 全卷积 + 用 Conv2d(1x1) 代替 Linear（对齐项目 RV1106 端侧部署/量化约束）。
- 参数量约 **1.7 万**（含 1x1 分类头 16k），远轻于 MyoText 的 BiLSTM-Attention。
- 激活层走可配置工厂：`elu` / `relu`（ANN）/ `lif`（复用 `lif_eegnet.LIFActivation`）。

## 5. LIF 化（`train_lif_finger.py`）

- 复用 `algorithm/lif_eegnet.py` 的 `LIFActivation`（surrogate gradient，硬重置，
  输出发放率 ∈ [0,1]，`decay=exp(-1/tau)`），**未改动原代码**。
- LIF 放在两个 pool 前（Block1/Block2 激活位点），发放率输出。
- 可配超参：`threshold` / `tau` / `timesteps` / `alpha`。
- 支持：`--activation relu|elu|lif`（同一脚本产出 ANN 基线与 LIF）、
  `--warm-start`（ANN 权重热启动，LIF 激活层无参数，state_dict 键零回归）、
  hold-out 早停、final test 只测一次、发放率诊断报告。

## 6. 精度与 MyoText 85.45% 的差距（诚实标注）

### 6.1 当前实测（仅 mock 合成数据冒烟，非真实精度）

| 配置 | 测试精度 | 说明 |
|---|---|---|
| relu（ANN 基线） | 93.75% | mock 数据可学习，非真实 |
| lif（surrogate，热启动+微调） | 91.67% | 同上，发放率 act1≈20% act2≈13% |
| 随机基线 | 12.5% | 8 类 |

> 以上数值**只证明「预处理 → CNN → LIF 化」整条管线可跑通、梯度可回传**，
> **不构成任何真实分类精度声明**。合成数据按手指放频率特征，可学习性远高于真实 sEMG。

### 6.2 真实精度：待数据

| 评估协议 | MyoText 论文 | 本复现（轻量 CNN） | 本复现（LIF 化） |
|---|---|---|---|
| 5-fold CV | 85.45% ± 3.36% | **待数据** | **待数据** |
| LOUO（留一被试） | 81.4% ± 3.76% | **待数据** | **待数据** |

### 6.3 架构差异（为什么不可直接对标）

| 维度 | MyoText | 本复现 |
|---|---|---|
| 骨架 | CNN-**BiLSTM**-**Attention** | 轻量**全卷积 CNN**（类 EEGNet） |
| 时间建模 | 双向循环 + 注意力池化 | 纯卷积 + 平均池化 |
| 参数量 | 大（含 LSTM 128×2 层等） | ~1.7 万 |
| 类脑化 | 难（循环/注意力） | 易（LIF 替换激活即可） |

**诚实结论**：本复现用轻量 CNN 替换 BiLSTM-Attention 是「类脑化优先」的取舍，
**牺牲了时序建模能力**；预期真实数据上的手指分类精度会**低于** MyoText 的 85.45%
（参考：emg2qwerty 原文跨被试泛化本就困难，CER 高达 51.78%）。两者精度**不可直接对标**；
真实差距需待数据落地、同协议（5-fold CV / LOUO）实测后填写上表。
