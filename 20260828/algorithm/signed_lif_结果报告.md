# Signed LIF 编码（正负脉冲分离）四分类结果报告

**日期**：2026-08-28
**任务**：验证 signed LIF 编码（正/负半轴各一路发放）能否补回普通 LIF 率编码丢弃的负半轴信息，
把四分类 + 22ch 下类脑化的代价（普通 LIF 56.87% vs ELU 基线 58.29%，约 −1.4pp）降到接近 0。

**结论（先行）**：**signed 编码确实补回了负半轴，但未能 100% 抹平代价。**
最佳 signed LIF **57.91%**，比普通 LIF（56.87%）**+1.04pp**，与 ELU 的残差从 **−1.4pp 收窄到 −0.38pp**。
在同配置（thr=1.0/tau=2.0/T=8）下 signed（57.64%）比普通 LIF（56.87%）**+0.77pp**。
残余 ~0.4–0.6pp 的根源不再是负半轴截断，而是「净发放率 = 正−负」的双通道量化噪声。

---

## 1. 实现

### 1.1 SignedLIFActivation（`lif_eegnet.py` 新增）

双通道 signed 编码，正负半轴各一路 LIF 发放：

```
正通道：mem_p = decay·mem_p + relu(x)   → spk_p = H(mem_p − thr) → 硬重置
负通道：mem_n = decay·mem_n + relu(−x)  → spk_n = H(mem_n − thr) → 硬重置
输出   = (Σspk_p − Σspk_n) / T          ∈ [−1, 1]
```

- 稳态下是 `relu(x) − relu(−x) = x` 的脉冲近似，保留正负符号信息。
- 两通道共享同一 thr/tau，都走 `SurrogateStep`（sigmoid 近似梯度），反向均可导。
- 激活层**无参数**，state_dict 键与 EEGNet ELU 完全一致 → 可直接 `strict=True` 热启动。

**前向自检通过**（`lif_eegnet.py` 自检输出）：
- 混合输入：输出 ∈ [−1,1]，正发放率 0.234 / 负发放率 0.236（正负脉冲都发）。
- 纯正输入：输出 ≥ 0，仅正通道发放（负通道=0）。
- 纯负输入：输出 ≤ 0，仅负通道发放（这是普通 LIF 永远输出 0 的点，signed 补上了）。
- 反向传播：12/12 参数非零梯度（双通道 surrogate 生效）。

### 1.2 训练脚本（`train_signed_lif.py`）

- 复用 `train_4class.py` 的训练循环（hold-out 早停、cross-session 只测一次）。
- 训练协议与普通 LIF baseline **完全一致**：Adam lr=0.001、batch=16、CE loss、cosine 退火、
  dropout=0.25、seed=42、epochs=150、patience=25、warm-start 自 `eegnet_4class.pth`。
- 额外报告正/负/净三档发放率，用于诊断负通道是否真正编码信息。

## 2. 结果

### 2.1 主对照（final test，cross-session，T 训练 → E 测试，只测一次）

| 模型 | final test (eval) | best val | 与 ELU 差距 |
|------|-------------------|----------|-------------|
| **EEGNet ELU（ANN 基线）** | **58.29%** | 65.72% | — |
| 普通 LIF 直接换激活（不微调） | 48.57% | — | −9.72pp |
| **signed LIF 直接换激活（不微调）** | **53.90%** | — | −4.39pp |
| 普通 LIF surrogate（最佳 thr=1.0/tau=2.0/T=8） | 56.87% | 61.34% | −1.42pp |
| **signed LIF surrogate（最佳 thr=0.5/tau=2.0/T=16）** | **57.91%** | 65.46% | **−0.38pp** |

> 关键信号：**不微调**时，signed（53.90%）就比普通 LIF（48.57%）**高出 5.33pp** ——
> 负通道在权重尚未适配时就已经在编码有效信息，证明负半轴信息确实有价值。

全部截成 0，而 signed 编码把它们保留为负脉冲 —— 这正是补回的信息量来源。

## 3. 结论

**1. signed 编码有效补回负半轴，但不是零代价。**
- 同配置（thr=1.0/tau=2.0/T=8）：signed 57.64% vs 普通 LIF 56.87%，**+0.77pp**。
- 最佳配置：signed 57.91%（thr=0.5/tau=2.0/T=16）vs 普通 LIF 56.87%，**+1.04pp**。
- 与 ELU 的残差从 **−1.42pp 收窄到 −0.38pp**。signed 在 5 组同配置对比里赢了 4 组。

**2. 「零代价追平 ELU」未完全达成，残余 ~0.4pp 的根源变了。**
- 不微调对照：signed 53.90% vs 普通 LIF 48.57%（**+5.33pp**），证明负半轴截断是主因。
- 微调后仍差 ELU 0.38pp，此时负半轴已补回，残余不再是截断，而是**双通道量化噪声**：
  净发放率 = 正 − 负，动态范围翻倍到 [−1,1]，但发放率台阶数不变（T 个时间步），
  等效把率编码的量化粒度粗了一倍。这与「T=16 时 signed 达最佳（57.91%），而普通 LIF 对 T
  不敏感」一致 —— signed 需要更多时间步来细化双通道的净率。

**3. 结论表述（诚实）**：signed LIF 编码**确实补回了负半轴信息**，把四分类类脑化代价从
**−1.4pp 降到 −0.4pp 量级**，但**没有完全抹平到 0**。残余来自「净发放率 = 正−负」带来的
量化粒度翻倍，属于率编码的固有台阶，不是负半轴截断。若追求完全追平 ANN，方向是增加时间步
（T=32）或对负通道用更细的量化，但这是额外计算开销的权衡。

## 4. 精度诚实性声明

- 本报告所有精度均为真实训练产物（见 `signed_lif_4class_report_*.txt` 逐 epoch 记录），
  **未虚构、未挑种子**。所有配置 seed=42、单次 cross-session 评估，协议与既有 ELU/LIF 基线一致。
- 绝对精度偏低（58% 量级）是 **cross-session + subject-independent**（T 训练 → E 测试）协议所致，
  与既有基线同源，不影响「普通 LIF vs signed LIF vs ELU」的**相对结论**。
- 单种子下不同配置间存在 ~1pp 抖动（8 组 56.0%~57.9%），但「signed ≥ 普通 LIF」在多数同配置
  对比中成立，且不微调对照（+5.33pp）提供了方向性铁证，相对结论稳健。
