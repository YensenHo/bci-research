ANN→SNN 转换精度报告（LIF-EEGNet 板载闭环 S1/S5）
=================================================

数据：BCIC IV 2a（8ch 二分类左/右手），train/eval 各 1296 试次。
标定：eval 前 200 试次；SNN decay=1.0（纯 IF 硬重置）；timesteps=16（默认）。

[1] 转换基线（naive 阈值标定：thr = 逐层全局最大正激活）
  ANN（ReLU 代理）        : 75.77%（eval 全量）
  标定阈值                : thr1=7.0018, thr2=6.0072
  SNN（timesteps=16）     : 50.93%（eval 全量）
  ANN→SNN 精度损失        : -24.85 pp   ← 如实记录，非「成功」
  act1 平均发放率         : 3.01%
  act2 平均发放率         : 0.43%

[2] 根因
  1) thr = 全局最大激活是单标量，被离群通道/时间点主导，绝大多数神经元激活远小于
     thr → 发放率≈0（act1 仅 3%），连续激活被压成近零。
  2) T=16 时发放率只有 0..16 共 17 档，粗量化丢信息。
  3) LIF 负半轴永不发放（率=0），与 ReLU 负半轴截断同源。

[3] 改进实验（数据驱动逐层归一化，Rueckauer 2017 式；snn_improve_exp.py，前 300 试次）
  ANN(ReLU 代理) acc@300 : 71.33%
  归一化后 λ1=7.0018, λ2=0.9554 → thr1=thr2=1.0
  naive  thr=max : T=16 50.00% | T=64 51.33% | T=128 51.33%
  归一化 thr=1.0 : T=16 57.00% | T=64 55.33% | T=128 55.00% | T=256 55.33%

  结论：归一化把 naive 的 ~50% 提到 ~55-57%，但仍在 ~55% 平台（ANN 71.33%），
        即使 T=256 不再提升。单标量 max 归一化 + 率编码 LIF 对该 EEG 任务的转换
        损失仍大（>10pp），属真实代价，非脚本 bug。更激进的方案（99.9 分位、
        逐通道归一化、burst/事件驱动、signed 双通道编码）留待后续。

[4] C 移植一致性（C-SNN vs PyTorch-SNN，逐位）
  宿主机 cc 自检 : max|diff|=4.75e-7，预测一致率 20/20 (100%)
  板载 RV1106     : max|diff|=4.87e-7，预测一致率 30/30 (100%)（真实 adb 输出）
  板载单次前向   : 370.80 ms（16 timesteps；ELU 单趟 23.25ms ×16 ≈ 371ms，符合预期）

诚实结论：
  - ANN→SNN 转换「跑通」指流程正确 + C 移植逐位一致，**不等于 SNN 精度达标**。
  - naive 标定 SNN 精度 50.93%（损失 24.85pp），归一化后 ~55%，均未追平 ANN。
  - 板载闭环验证的是「C-SNN == PyTorch-SNN」，已通过；端到端精度未达标，如实标注。
