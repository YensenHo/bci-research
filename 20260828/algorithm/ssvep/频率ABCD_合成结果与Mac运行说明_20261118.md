# 频率 A/B/C/D：合成结果与 Mac 交接

## 状态与结论

四类合成试验和 20 次打乱训练/验证标签的置换对照已完成；真实 SSVEP 尚未运行。C 在该合成例子上达到 100%，但 **C 显式获得四个目标频率作为模板**，不能称为无先验学习或新颖发现。C 未训练时也有 46.19% 准确率；其标签置换零分布均值 39.48%，范围 8.50%–69.63%，不能错误地要求这一带先验的模型每次都等于 25%。20 次中 0 次达到已训练 C 的 100%；次数有限且探索性，不能据此做论文级显著性结论。

## 合成实验

使用 250 Hz、1 秒、6 通道、8/10/12/14 Hz；每条试次独立生成随机相位、幅度（0.7–1.3）、通道相位偏移及高斯噪声。训练/验证/测试分别 512/256/1024 条，四类严格平衡；划分随机种子 11001/22002/33003，逐条 SHA-256 检查无重复，模型种子 42，最多 20 轮、patience 8，训练块第 80 百分位差分阈值。各模型使用**同一**编码事件（训练/验证/测试每试次均值约 298.8/300.0/302.1 个）。

| 条件 | 测试准确率 | 参数 | 最佳/实际训练轮数 |
|---|---:|---:|---:|
| A：16 神经元＋原末膜/率读出 | 29.10% | 260 | 17 / 20 |
| B：64 神经元＋原读出 | 35.94% | 1028 | 20 / 20 |
| C：16 神经元＋已知频率读出 | 100.00% | 324 | 20 / 20 |
| D：20 神经元＋原读出 | 27.05% | 324 | 19 / 20 |

每个目标模板对隐藏脉冲流做整窗 sin/cos 投影，取幅值，并以幅值与幅值平方作为该目标的受限可训练读出；这是模拟代码上的浮点整窗运算。未训练 C 和每个打乱训练/验证标签的 C 都仍保有正确的目标频率模板，因此其非随机表现本身是重要对照，不能把全部增益归给训练。置换模型用真实测试标签评分；这些数、训练曲线、数据指纹与事件计数保存在 `results/gate1_frequency_abcd_synthetic_20261118/seed42.json`。四类准确率在相同 1024 条测试试次上得到，第二种子或新测试集仍可变化；合成数据不是脑电证据。

## 实现、测试与真实数据边界

`gate1_frequency_abcd.py` 提供 A/B/C/D，按参数量选择 D 宽度。40 类时 A/B/C/D 参数量为 **872 / 3368 / 1512 / 1496**；C 与 D 接近但函数形式、运算数和输入先验不同，非完全等价。所有模型训练/验证按相同规则选择验证损失最小的检查点。模型保存内部总脉冲数与 Python 批量推理时间，但该时间不含完整预处理，不能当硬件时延、功耗或实时能力。

`test_gate1_frequency_abcd.py` 两项通过：合成标签平衡和无重复、事件形状及训练阈值；真实四频率目标索引按频率值而非轴排序确定、C/D 参数量核查、A 与原 LIF 率读出前向一致、C 跨试次重置和有限梯度。另用合成 NPZ 冒烟真实四类和 40 类入口及三种子汇总接口；这些冒烟结果不是真实 EEG 结果。

## Mac 上执行真实数据

使用原 Gate 1 已有同一 NPZ 与频率文件；命令强制校验当时记录的 SHA-256。NPZ 不带被试 ID，必须人工确认 S1–S10 顺序。下面 CPU 与此前 Mac 报告口径一致；使用 MPS 时三种子保持同一后端，并如实标注。`OUT` 放仓库外，默认每模型最多 100 轮、patience 25。运行耗时较长；建议先执行测试及 `--subjects 1 4 7` 冒烟，此三人按已知 CCA 表现选取，**不得作为无偏结论**。

```bash
cd /path/to/bci-research/20260828/algorithm/ssvep
RAW=/Users/heyixuan/BCI/20260828/algorithm/ssvep/raw
OUT=/Users/heyixuan/BCI/gate1_ssvep_local
NPZ="$OUT/occipital_onset05.npz"
FREQ="$RAW/Freq_Phase.mat"
NPZ_SHA=e26a3d0b08a74bf90f0cd0a84a68ec822ca162a29a9534fe2f240235d7aefd9b
FREQ_SHA=6059f712688ec9e5df0beace9244dc0a4b03c418dacdef86bac50cf5a7c6abd
python test_gate1_frequency_abcd.py
for task in 4 40; do
  for seed in 42 123 2024; do
    python gate1_frequency_abcd.py --mode real --task "$task" --npz "$NPZ" --freq-phase "$FREQ" --expected-npz-sha256 "$NPZ_SHA" --expected-freq-sha256 "$FREQ_SHA" --seed "$seed" --device cpu --output "$OUT/abcd_${task}_${seed}.json"
  done
  python analyse_frequency_abcd.py "$OUT/abcd_${task}_42.json" "$OUT/abcd_${task}_123.json" "$OUT/abcd_${task}_2024.json" --output "$OUT/abcd_${task}_paired.json"
done
```

四类通过实际 `freqs` 中值匹配 8/10/12/14 Hz，不默认目标轴排序。40 类沿用文件目标顺序。每人 1–4 块训练、5 块验证、6 块测试；各人每类仅四个训练试次、一个测试试次。脚本按被试完成写 JSON，全部完成才标 `status=completed`；中断后目前需要重新运行，不要把部分文件当完整结果。严格报告 3 种子、所有人、逐轮训练/验证曲线、输入与内部事件量、每人测试准确率。不要提交 EEG、模型权重、缓存或逐试次预测。

聚合脚本先按被试平均种子差，再报 B/C/D 相对 A 和 C 相对 D；仅 40 类、10 个不同被试、B 或 C 相对 A ≥7/10 人提高、均差 ≥5 pp、平均准确率 ≥10% 才标开发门槛通过。C 还需比较 D、强非 SNN 基线及输入/计算成本；该开发门槛不是统计显著、跨被试结论或一区保证。
