# 方法学注记：对称二分类的标签置换呈双峰，不作 50% 零假设

## 结论

在两类互为镜像的对称二分类任务（如 Gate 0 的"ch0 早于 ch1"vs"ch1 早于 ch0"、正负极性顺序），**"置换训练标签 → 仍用原始测试标签评分"的单次准确率不是干净的 50% 零假设**，而是双峰分布（可能在 ~0% 或 ~50% 两端摆动）。不能拿单次落在 [47%, 53%] 当作控制通过判据。

## 机制

打乱训练标签后，模型仍能学到"早 vs 晚"这类**特征结构**，只是标签赋值变任意：

- 若乱序标签恰好接近真标签的**反转**，模型学出反向映射，对原始测试标签得到 ~0%（反相关，低于 50%）。
- 若乱序标签接近随机，得到 ~50%。
- 若恰好部分对齐真标签，也可能偏高。

故单次值双峰、范围宽，均值才 ~50%。

## 证据（Gate 0，2026-11-18）

时序 LIF 对原始标签训练达 ≥99.8%；计数/平均率对照 50%。20 次训练标签置换审计（每次仍用原始测试标签评分）：

- 通道先后任务：均值 50.95%，范围 26.22%–91.60%
- 极性先后任务：均值 49.63%，范围 14.36%–82.06%
- 两任务各 0/20 达到原标签训练的 100%

而"置换训练 → 置换测试标签"20 次均值分别为 50.24%、50.05%，范围约 49%–51.5%，是紧的 50% 零假设。

## 正确判据

对称二分类（或任何标签可翻转反相关的任务）的置换零假设，用：

1. **计数/平均率对照 = 50%**（证明非时序信息不足以解题）；
2. **置换训练 → 置换测试标签 ≈ 50%**（紧零假设）；
3. 或报告**完整置换分布**并看真模型是否落在分布外，而非单次值。

弃用"置换训练 → 原始测试标签单次 ∈ [47%, 53%]"。

## 边界

本注记只针对标签可翻转的对称任务；对不对称任务，置换训练→原始测试仍是合理零假设。判断是否"泄漏"要看完整分布是否整体偏高（泄漏表现为置换下也普遍高分），而非单次点估计落在区间外。
