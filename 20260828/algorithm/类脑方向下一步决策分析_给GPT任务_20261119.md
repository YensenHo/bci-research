> 背景：简化 signed-event LIF 管线在 MI / SSVEP / ISRUC 三个范式都无增益，到了方向存续的决策点。

## 一、已有证据（直接引用，无需重跑）

| 实验 | 结论 | 证据 |
|---|---|---|
| Gate 0 合成时序/极性正对照 | **通过** | 状态式 LIF 种子 42/123 均 ≥99.8%，计数/平均率对照 50%——工具本身能用时序 |
| MI 运动想象 | 阴性 | 18 训练矩阵（6 变体 × 3 种子），类脑变体无稳定机制增益 |
| Gate 1 SSVEP | 证伪 | CCA 27% / ridge 34.5%，LIF 2.75%（随机）；A/B/C/D 均未过门槛 |
| ISRUC 睡眠分期（12 折 LOOCV） | fail | LIF 45.28% < PSD-Ridge 61.33%，配对差 −16.05pp，2/12 改善，Wilcoxon p=0.0122 |

**关键区分（分析的前提）**：当前实现是「简化 signed-event LIF」——117 参数、每 5 秒窗口 reset（不连续积分整 30 秒）、事件编码用绝对一阶差分 80% 分位阈值。它 **≠** STCA-SNN（真实时间步 × 特征 × 空间 + 时序注意力）和 BD-SNN（正负脉冲 + 动态阈值神经元方程）原方法。原方法尚未被忠实迁移复现。

## 三、必须覆盖的分析内容

### 1. 证据链解读
三个范式 fail 到底排除了哪些解释、保留了哪些？诚实区分：
- 能排除的：这条「简化管线」在频域（SSVEP）、空间（MI）、长时序（睡眠）三个维度都没有增益——「简化管线」本身不成立。
- 不能排除的：原方法（STCA/BD）可能仍有效（因为当前实现不忠实）；「容量不足」「5 秒 reset 丢上下文」这两个实现层解释尚未单独检验。

### 2. 失败原因分解（每个给可信度 + 已有证据支撑/反证）
至少覆盖五个候选解释，逐一判断：
1. 实现不忠实（简化管线 ≠ 原方法）
2. 机制无效（「尖峰编码 + 膜积分」在 EEG 上本就无增益）
3. 任务不敏感（选的范式测不出时序价值）
4. 容量不足（117 参数太小，对照不公）
5. 5 秒 reset 丢整夜上下文（长程状态假设）

### 3. 下一步选项（每个给：假设 / 验证成本 / 成功概率判断 / 止损条件）
至少覆盖：
- **A. 长程连续状态验证**：整 30 秒/整夜连续积分 + 容量匹配 ANN 对照，验「长程状态是否提供增量」
- **B. 忠实迁移原方法**：逐式复现 STCA-SNN / BD-SNN 原文方程 + 单元测试 + EEG 维度映射，验「原方法」而非「简化管线」
- **C. 止损换方向**：接受三范式无增益，回到科研主轴的其他方向（如蒸馏抗噪鲁棒性这条已跨数据集坐实的线）
- **D. 换范式/换机制**：若还要在类脑 SNN 内换，换到 ERP/P300 或换机制（BD 动态阈值 vs 时序注意力），评估是否值得

### 4. 明确推荐 + 决策门槛
- 给出**唯一**的明确推荐（不列清单和稀泥），说明理由。
- 给出「如果选 X，什么条件下止损」的硬门槛（沿用已有门槛口径：≥7/10 或 ≥7/12 被试提高且平均 ≥2pp，否则不加码）。
