## 数据及更正

此前预处理把 MATLAB 的 1 基 trial 直接用作 Python 下标，窗口比指定时间晚 1 点（4 ms）。参考 [MOABB 的 BNCI 读取实现](https://github.com/NeuroTechX/moabb/blob/develop/moabb/datasets/bnci/base.py)，已改为 `trial - 1`，重新生成训练及测试数据；不能与旧窗口下的数值混成同一矩阵。新数据显式记录被试 ID。

对 A01T 首个有效试次（MATLAB onset 251），独立滤波后按 `onset - 1 + 625` 切取并标准化，与生成的首条样本逐元素一致（最大绝对误差 0）；该检查验证代码切窗实现，索引语义依据上述数据读取实现。

18 个原始 MAT 文件来自 [公开镜像](https://github.com/ParthanOlikkal/BCI_Competition_IV_2a)，均与镜像提交 `dad02c61cea8a4a3a427a0f10f521fa59bdeb765` 的对应 Git blob 哈希匹配；尚未获得官方源校验和，不能宣称已逐字节验证为官方原版。9 名被试每人两会话各 288 试次，四类均衡。

## 设计与解释边界

每个种子使用本次修正后的同一训练数据、随机 15% 试次作为训练会话内早停信号，并使用相同的该种子 ReLU 热启动；三个种子分别为 42、123、2024。会话 T 用于拟合和早停，会话 E 用于跨会话评估。训练与验证来自同人同会话，验证并不独立；此设计不支持跨被试泛化结论。历史轮次已观察过同一批 E 会话结果，后续对照是开发性复核，不是全新独立确认。

沿用先前的每个连续 run 双向滤波、再切窗与逐试次标准化流程；这不是在线因果预处理，训练/早停试次也共享同一段连续记录。未按数据集中的伪迹标记排除试次。所有对照使用相同处理方式，部署及真正独立验证需要另行设计。

五组为单极 LIF 基线、固定阈值双极、双极自适应阈值、注意力＋单极 LIF、注意力＋双极自适应阈值。基线与固定阈值双极的对比考察双极机制；固定阈值双极与双极自适应的对比考察自适应阈值；注意力＋双极自适应与双极自适应的对比考察该组合中的注意力。两个变化同时出现时不能归因于某一个组件。本实现为论文机制的简化启发式版本。

逐种子以 9 个被试为配对单位，报告准确率差的均值、样本标准差、正负及平局数量与探索性 Wilcoxon 检验。跨种子比较先在每位被试内部对种子取平均，再以 9 名被试为单位；不把重复种子当作额外独立受试者。多个检验、样本量小及后验选择均限制 p 值的解释。

从算法目录使用独立输出目录运行（3 个种子分开调用）：

```text
python preprocess_4class.py --raw-dir RAW --output-dir DATA
python run_stca_matrix.py --data-dir DATA --results-dir RESULTS --seed 42
python run_stca_matrix.py --data-dir DATA --results-dir RESULTS --seed 123
python run_stca_matrix.py --data-dir DATA --results-dir RESULTS --seed 2024
python analyse_stca_subjects.py --results-dir RESULTS --output paired.json
```

中断续跑可在对应命令加 `--resume`：已完成且哈希匹配的模型会跳过，未完成模型从头重训；不保存中间轮次。应保持训练代码版本不变，续跑检查不覆盖代码哈希核验。
