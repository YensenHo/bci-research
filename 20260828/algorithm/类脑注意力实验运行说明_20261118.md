# EEG-TCNet 注意力与双极阈值：开发运行说明

## 定位与边界

此实现是受 STCA、BD-SNN 启发的探索版本：注意力作用于池化后的 EEG 特征时间轴，采用浮点 softmax、线性运算及整窗上下文；既不是原 STCA 精确复现，也不是事件驱动或在线实现。双极激活使用发放后增加阈值的局部自适应，属于简化设计，不是原 BD-LIF 数学公式复刻。其内部 8 步是固定输入的仿真步，输出净发放率，不是真实 EEG 时间脉冲序列。不能据此声称硬件节能或论文创新。

旧 62.42% 基线是**跨会话**：同一批被试 T→E，会话级分离不是跨被试。`train.npz` 试次随机 15% 做早停验证，可能同人同会话，不能声称独立被试。开发阶段使用；后续跨被试需按被试分组重新设计数据及验证。

## Mac 环境

准备 Python、PyTorch、NumPy、SciPy；安装命令依 Mac 的 PyTorch 官方指南选择。进入仓库：

```bash
cd bci-research/20260828/algorithm
python test_eeg_tcnet_stca.py
```

准备 `DATA/train.npz`、`DATA/eval.npz`，键 `X`、`y`，X 形状 `(N,1,22,500)`、标签 0–3。使用 `python preprocess_4class.py --raw-dir RAW --output-dir DATA` 指定本机路径；先核实 A01–A09 T/E 数据及许可。不要将原始数据或生成的 NPZ 提交。预处理和划分须记录数据哈希、参与者与会话。

热启动模型必须来自未使用测试标签挑选的 ReLU 基线，格式应含 `state_dict`；该权重及其来源当前未核实，若不存在不得默默降级为随机训练或宣称复现 62.42%。三组使用同一文件、数据和 seed。输出放在仓库外的 `RESULTS` 目录。

```bash
DATA="$PWD/data_4class"
WARM="/absolute/path/to/eeg_tcnet_4class_relu_brief.pth"
RESULTS="/absolute/path/to/results"
python train_eeg_tcnet_stca.py --data-dir "$DATA" --warm-start "$WARM" --output-dir "$RESULTS/baseline-42" --variant baseline --seed 42
python train_eeg_tcnet_stca.py --data-dir "$DATA" --warm-start "$WARM" --output-dir "$RESULTS/attention-42" --variant attention --seed 42
python train_eeg_tcnet_stca.py --data-dir "$DATA" --warm-start "$WARM" --output-dir "$RESULTS/attention-adaptive-42" --variant attention_adaptive --seed 42
```

可对 123、2024 重复，但不要以测试集选设置。默认 CPU，Mac 可选 `--device mps`（兼容性待验证）。各次保存 `summary.json`（含数据/权重 SHA-256、样本量、验证及测试准确率）和 `model.pth`。先固定设计、超参、预算和验证规则；正式比较应额外包含仅 adaptive 与 signed 固定阈值，以分离符号和阈值效应。需另核对热启动权重是否已使用 E 会话或其标签选择，以免泄漏；若无法排除，使用重新训练且未接触测试标签的权重。

历史 62.42% 不能视为本次实验必须复现的结果；真实运行结果以对应实验报告为准。软注意力和动态阈值增加计算、内存及功耗开销；未来需目标平台实测。不要将模型输出或缓存与参与者隐私材料上传。

## 当旧热启动权重不可用

使用新版本 `--variant relu` 在训练集从头训练预热模型，不提供 `--warm-start`；该阶段只用于预热，不输出测试准确率。每个种子使用各自 ReLU 权重，随后三种 LIF 变体共用对应种子的相同权重和训练/验证划分：

```bash
python train_eeg_tcnet_stca.py --data-dir "$DATA" --output-dir "$RESULTS/relu-42" --variant relu --seed 42
python train_eeg_tcnet_stca.py --data-dir "$DATA" --warm-start "$RESULTS/relu-42/model.pth" --output-dir "$RESULTS/baseline-42" --variant baseline --seed 42
python train_eeg_tcnet_stca.py --data-dir "$DATA" --warm-start "$RESULTS/relu-42/model.pth" --output-dir "$RESULTS/attention-42" --variant attention --seed 42
python train_eeg_tcnet_stca.py --data-dir "$DATA" --warm-start "$RESULTS/relu-42/model.pth" --output-dir "$RESULTS/attention-adaptive-42" --variant attention_adaptive --seed 42
```

seed 123 同理。`preprocess_4class.py` 现在支持 `--raw-dir` 和 `--output-dir`，默认路径仍保留；缺少任何指定被试/会话的原始文件时直接报错。此过程是新预热权重，不能称为复现历史权重结果。验证依然是同受试者的训练会话随机试次，因此不独立。
