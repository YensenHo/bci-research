# 蒸馏 4 类 22ch → 端侧闭环（2026-10-03）

> 把「蒸馏→类脑→端侧」闭环从 8ch 二分类推广到 **4 类 22ch**（更难、更接近真实可穿戴场景）。

## 结论（最终）

蒸馏训出的 **LIF-EEG-TCNet 学生（30% 标签，热启动 relu 权重）** 精度 **56.40%**，追平 relu 学生
57.25%（−0.85pp，**类脑化零代价在蒸馏场景下成立**）；导出 C 后端侧推理与 PyTorch/numpy 参考
**严格逐位一致（50/50 样本，max|diff| = 0.000e+00）**。端侧闭环在 4 类 22ch 上成立。

## 精度对比（关键）

| 学生（蒸馏 30% 标签） | 精度 | 说明 |
|---|---|---|
| relu（60 epoch，旧报告） | 55.42% | distill_4class_relu_report |
| LIF 随机初始化 | 49.23% | surrogate 训练收敛难（第一版） |
| relu（100 epoch） | 57.25% | 热启动源 |
| **LIF 热启动** | **56.40%** | 追平 relu，−0.85pp |

- **热启动是 LIF 蒸馏的关键**：随机初始化 LIF 蒸馏只有 49.23%，热启动 relu 权重后跳到 56.40%，
  追平 relu——证实「LIF 训练难」是初始化问题，不是 LIF 蒸馏红利上限。

## 完整链路

| 步骤 | 脚本 | 结果 |
|---|---|---|
| ① 训练 relu 学生（热启动源） | `train_distill_4class_save.py --student relu` | teacher 66.17%，relu 学生 30% 标签 57.25% |
| ② LIF 热启动蒸馏 | `train_distill_4class_save.py --student lif --warm-start <relu ckpt>` | LIF 学生 56.40%，保存 checkpoint |
| ③ 导出 C 头 | `export_tcnet_snn_weights.py --checkpoint distill_4class_lif_ws_30pct_s42.pth` | BN 折叠 + 导出（9344 参数，TCN 8 个 LIF 位点） |
| ④ 逐位验证 | `verify_tcnet_bit_exact.py --checkpoint ... --n 50` | **50/50 逐位一致，0 误差** |
