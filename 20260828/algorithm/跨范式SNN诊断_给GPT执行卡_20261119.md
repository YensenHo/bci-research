## 一、背景与当前状态（GPT 接手时须知）

**要回答的问题**：带符号尖峰编码 + 膜积分 + 尖峰读出 的类脑 SNN 管线，在脑电解码上相对经典基线（ANN/CCA/ridge/黎曼）有没有机制增益。参考原方法 STCA-SNN / BD-SNN / PG-SNN（组合本身不是空白，不宣称首创）。

**已完成的状态**：

1. **MI 运动想象**：18 组训练矩阵（6 变体 × 3 种子）跑完，类脑变体无稳定机制增益（阴性）。
2. **Gate 0 合成时序/极性正对照**：通过。状态式 LIF 在种子 42/123 下均 ≥99.8%，计数/平均率对照 50%——工具本身确实能用时序信息。
3. **Gate 1 SSVEP 诊断**：CCA 27%、ridge 34.5%（数据/频率映射正确），但 LIF 2.75%（接近随机）；A/B/C/D 四条件均未过门槛（容量 B 仅 +0.33pp、频率读出 C 仅 +1.33pp，均值 2.75/3.75% 远低于 10% 门槛；C 未训练 2.08% 低于偶然 2.5%）。
4. **结论**：SSVEP 上「差分事件→LIF 膜积分→尖峰读出」几乎不保留频率信息，已决定停止在 SSVEP 上堆模型。

**下一步**：回到更适合科研问题的数据范式做跨任务诊断，判断这条管线是「SSVEP 特有失败」还是「跨范式普遍不保留信息」。首选 **ISRUC 睡眠分期**（数据脚本已备好），癫痫 CHB-MIT 作为备选。

## 二、数据方案（已解决，脚本已推仓库）

| 步骤 | 脚本 | 说明 |
|---|---|---|
| 下载 | `20260828/algorithm/download_isruc_full.py` | 从 NEMAR 公开 S3 下载 12 人 `.edf` + events.tsv（约 1.6GB），内嵌 URL + 按对象字节数校验 |
| 预处理 | `20260828/algorithm/preprocess_isruc_subjects.py` | C3-A2 单通道 → 200→100Hz → 0.5-35Hz 带通 → 30s epoch → 5 类 → 逐 epoch z-score，**保留 subject 标签**，支持 12 折 LOOCV |

**EDF 边界核查修正（2026-11-19）**：此前「约缺后 1/3、截断前半段」的判断来自错误的文件长度估算方式，不能继续引用。EDF 每个通道每个 data record 的采样数可能不同，必须按 header 中每通道 `n_samps` 计算 record 字节数。重新核对后，12/12 文件的完整 record 数均与 EDF header 一致；事件标注末端与文件实际时长匹配。I001/I002 有额外尾随字节，MNE 对其发出 warning，但没有证据表明缺少 header 声明的完整 records。此项内部一致性检查不等同于与上游原始文件逐字节核验，因此报告须写「NEMAR 对象字节数与 EDF header/事件时长内部一致」，不能写成已验证官方原件，也不能再称「截断前半段」。I011 仅有 C3-M2，预处理按规则回退并在元数据记录；其他 11 人使用 C3-A2。另已将 200→100 Hz 由抽点改为抗混叠重采样。

**LOOCV 用法**（预处理输出 `data_subjects.npz` 含 `X/y/subject` 三数组）：

```python
d = np.load('data_subjects.npz'); X, y, subj = d['X'], d['y'], d['subject']
for s in range(12):
    tr = subj != s; ev = subj == s
    model.fit(X[tr], y[tr]);  acc = score(model, X[ev], y[ev])
```
