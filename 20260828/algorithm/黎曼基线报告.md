# 黎曼几何分类器基线报告（BCIC IV 2a 四分类 22ch，cross-session）

**日期**：2026-08-31
**任务**：经典黎曼几何路线 vs 我们的 DL 路线（LIF-EEG-TCNet），在完全相同的 cross-session 协议下做论文级对照。
**结论（先行）**：**黎曼基线最优 47.45%，LIF-EEG-TCNet（HBC 增强）63.58% 领先 +16.1pp**。经典黎曼路线在"跨会话 + 跨受试池化"协议下显著落后 DL；其端侧极轻（约 1~3.7 ms/试次估算、纯 C 可写），但精度差距使其不足以作为芯片方案的替代路线。

## 1. 协议与数据（与 DL 基线完全一致，保证可比）

| 项 | 值 |
|---|---|
| 数据 | `data_4class/{train,eval}.npz`，BCIC IV 2a 22 EEG 通道，四分类 {左/右/双脚/舌头} |
| 预处理 | 0.5–50Hz 带通 + 50Hz 陷波，cue 后 [0.5, 2.5]s 分段（500 样本），每段 z-score（与 DL 完全一致） |
| train / eval | 各 2592 试次（9 受试 × 288），类别完全均衡，chance = 25% |
| **cross-session 协议** | train = T 会话（A\*T，2592 试次）拟合 → eval = E 会话（A\*E，2592 试次）只测一次；9 受试池化单模型（与 DL 基线同协议） |
| DL 对照 | LIF-EEG-TCNet + HBC 增强 clean **63.58%**（`eeg_tcnet_4class_report_lif_hbc_aug_s42.txt`，single-seed s42，MPS ±1.7pp 波动带）；EEGNet ELU **58.14%**（`eegnet_4class_report_proto25.txt`） |

## 2. 方法（经典黎曼管线，numpy/scipy 手写实现，无 pyriemann 依赖）

管线（Barachant 2013 切线空间范式）：

1. **每试次样本协方差**：C_i = (1/499)·X_i X_iᵀ ∈ SPD(22)，X_i 为 22×500
2. **协方差正则化（shrinkage，网格参数 ①）**：C_reg = (1−α)·C + α·(trace(C)/22)·I，α ∈ {0.0, 0.1, 0.3, 0.5}
3. **参考点 P = 黎曼（Karcher）均值**：SPD 流形不动点迭代 M ← M^{1/2}·expm(mean_i logm(M^{−1/2} C_i M^{−1/2}))·M^{1/2}（收敛 tol 1e-9；另报告算术均值 / 对数欧氏均值作参考点的影响，非网格项）
4. **切线空间投影**：T_i = logm(P^{−1/2} C_i P^{−1/2})，上三角向量化（非对角 ×√2，保 Frobenius 范数），维度 22·23/2 = 253
5. **分类器（网格参数 ②）**：逻辑回归（multinomial/lbfgs/C=1.0）或 LDA（solver='lsqr', shrinkage='auto'）

实现与验证要点（全部真实运行）：

- pyriemann 因环境代理问题安装失败（pip 直连与清华镜像均不可达），按预案改用 numpy 手写，数学内核自包含、可复现；
- **三项数学自检全部通过**：①切线向量范数 = 黎曼距离（max|Δ|=1.05e-4）；②白化恒等 P^{−1/2}·P·P^{−1/2} ≈ I（max|Δ|=4.8e-13）；③批量 logm 与 scipy.linalg.logm 逐元素一致（max|Δ|=1.4e-4）；
- 过程教训（诚实记录）：批量矩阵函数 `U·diag(s)·Uᵀ` 曾误写为 `diag(s)`（特征向量结构被丢弃，分类器只能看到"对数方差"对角信息，全量精度仅 37.65%）。范数自检对此类 bug 不敏感（Frobenius 范数对正交变换不变），**白化恒等自检捕获**。修复后重跑全部结果，本报告数字均为修复后产物；
- 本管线全确定性（LDA/LR 无随机初始化，numpy/scipy CPU 计算，不涉及 MPS），无 seed 波动问题。

## 3. 结果

### 3.1 网格：协方差正则 α × 分类器（cross-session，eval 2592 试次）

| α | 分类器 | train_acc | **eval_acc** |
|---|---|---|---|
| 0.0 | LR | 64.97% | 47.38% |
| 0.0 | **LDA** | 62.77% | **47.45%** ★ |
| 0.1 | LR | 57.18% | 46.49% |
| 0.1 | LDA | 61.57% | 46.18% |
| 0.3 | LR | 50.27% | 44.56% |
| 0.3 | LDA | 60.22% | 45.56% |
| 0.5 | LR | 46.84% | 42.63% |
| 0.5 | LDA | 58.14% | 44.91% |

- 最优 **α=0.0 + LDA → 47.45%**（train 62.77%），LR 同 α 下 47.38% 几乎持平；
- **shrinkage 在本数据上有害**：α 从 0→0.5 精度单调下降（47.45→44.91%）。原因：本数据每试次已 z-score（通道方差≈1），协方差谱本身良态可用（min eig 9.8e-5）；向恒等矩阵收缩抹平了通道间判别结构。经典 Ledoit-Wolf 最优收缩是数据驱动的（不在本次 ≤2 参数网格内，见 §6 展望）。

### 3.2 参考点选择的影响（固定 α=0.0，LR，补充信息非网格）

| 参考点 | train_acc | eval_acc |
|---|---|---|
| 黎曼均值 | 64.97% | 47.38% |
| 算术均值 | 64.81% | 47.38% |
| 对数欧氏均值 | 64.74% | 47.42% |

**结论：参考点选择对精度几乎无影响（≤0.04pp）**——切线空间映射下参考点只改变坐标系，对线性分类器近似不变。这也意味着经典管线可以省略黎曼均值迭代（训练期 15~44s 的一次性开销），直接用算术均值即可，端侧实现更简单。

### 3.3 最优配置混淆矩阵（α=0.0, LDA，eval 2592 试次）

```
         预测:  左     右    双脚   舌头   (行=真实)
  真实 左  :   324    169    110     45    每类 50.00%
  真实 右  :   141    370    107     30    每类 57.10%
  真实 双脚 :   113    130    317     88    每类 48.92%
  真实 舌头 :   120    149    162    217    每类 33.49%
```

- 左/右/双脚三类 48.9~57.1%，**舌头仅 33.5%**（大量被误判为双脚/右/左）——舌头运动想象的协方差空间模式与其他三类区分度最低，这是空间统计特征的固有局限，与 DL 模型观察到的现象一致但更严重。

## 4. 精度对比：黎曼 vs DL（同协议，cross-session）

| 路线 | 模型 | eval_acc | 参数量 | 每试次计算量 |
|---|---|---|---|---|
| 经典黎曼 | 协方差→切线空间→LDA（α=0） | **47.45%** | 33,147（LDA） | ≈0.74 MFLOP |
| 经典黎曼 | 协方差→切线空间→LR（α=0） | 47.38% | 1,016（LR） | ≈0.74 MFLOP |
| DL（ANN） | EEGNet ELU | 58.14% | 2,396 | ~50.5ms 板载实测* |
| **DL（类脑）** | **LIF-EEG-TCNet + HBC 增强** | **63.58%** | 9,512 | ~50.5ms 板载实测* |

\* 板载单次前向实测（`芯片能力全景_20260829.md`，2s 窗口，40× 实时余量）；DL 数字为 single-seed（±1.7pp 波动带，s123 时 LIF 基线 61.11%）。

**差异分析（诚实）**：

1. **DL 领先 +16.1pp（63.58% vs 47.45%），且对 seed 波动稳健**：即便取 DL 波动带下沿（61.11%），仍领先 ≥ +13.7pp。
2. **根本原因——信息类型**：黎曼管线只利用 2s 窗口的**空间二阶统计（22×22 协方差）**，时间结构仅以"整体协方差"形式隐式存在；而 LIF-EEG-TCNet 用 63 点前端卷积 + 膨胀因果 TCN 显式建模**时间动态**（ERD/ERS 的时变模式），并带非线性（LIF/ELU）与深度特征。本数据 4 类 MI 的判别信息主要承载在时域动态中，空间协方差不足以支撑 4 分类。
3. **协议难度**：cross-session + 9 受试池化是黎曼路线最不利的协议（空间协方差模式跨会话/跨受试漂移大）。文献中黎曼方法在 BCIC 2a 四分类的 60~70% 多为 within-subject / LOOCV；本协议下 47.45% 处于经典方法的合理区间（文献 cross-subject 类似协议约 40~50%）。
4. **参考点/分类器鲁棒性**：三种参考点、LR/LDA 结果高度一致（42.6~47.5%），说明 47.45% 是"方法天花板"而非调参假象——经典路线在本协议下没有隐藏的甜区。
5. **shrinkage 反直觉**：传统直觉"协方差必加正则"，本数据上 α=0 最优；说明数据预处理（z-score）已把协方差拉到良态，正则化反而破坏判别结构。

## 5. 端侧评估（黎曼管线，RV1106）

### 5.1 参数量

| 方案 | 参数量 | 说明 |
|---|---|---|
| LR | **1,016** | 253×4 + 4 bias |
| LDA | 33,147 | 4×253 类均值 + 253×254/2 共享协方差上三角 + 先验 |
| 参考点 P^{−1/2} | 484 | 22×22 矩阵，训练期算好固化 |

### 5.2 计算量（每试次，float32，22ch×500 样本）

| 阶段 | 运算 | 量级 |
|---|---|---|
| 协方差 | 22×22×500 MAC | 242,000 MACs |
| 白化 P^{−1/2}·C·P^{−1/2} | 2×22×22 矩阵乘 | ≈42.6 kFLOP |
| logm（对称特征分解） | 22×22 eig | ≈85 kFLOP |
| 向量化 + LR 推理 | 253×4 MAC | 1,012 MACs |
| **合计** | | **≈0.74 MFLOP/试次（全流程）**，推理期（P^{−1/2} 预计算）≈0.65 MFLOP/试次 |

### 5.3 C 实现可行性

**完全可行，且比 SNN 部署更简单**：

- 算子全集 = 矩阵乘 + 对称特征分解（Jacobi 旋转，22×22 固定规模）+ 逐元素 log/exp + 上三角向量化 + 一次矩阵-向量乘；**全部是教科书级纯 C 算法**（Jacobi eig 约 100~200 行），无需 BLAS/LAPACK 依赖，float32；
- 内存：单试次仅需 22×22×4B ≈ 2KB 工作区，微控制器级都绰绰有余；
- 训练期（黎曼均值、LR/LDA 拟合）在宿主机完成，板端只有推理：协方差 + 1~2 次 eig + 点积；
- 与 LIF-EEG-TCNet 的 C 部署（膨胀因果卷积 + LIF 状态机 + 逐位一致验证）相比，黎曼 C 实现工作量约 1/3~1/2。

### 5.4 RV1106 耗时估算（估算值，未上板实测）

| 场景 | 估算 |
|---|---|
| 全流程（含参考点白化） | **1.5~3.7 ms/试次** |
| 推理期（P^{−1/2} 预计算） | **1.3~3.3 ms/试次** |
| LIF-EEG-TCNet 板载实测（对照） | 50.5 ms/试次（2s 窗口） |

估算口径：RV1106 双核 A7 @~1.2GHz 标量 FP32 有效吞吐 0.2~0.5 GFLOP/s（无 NEON 向量化保守区间），t = MFLOP/(GFLOP/s)。**诚实声明：此为基于算子量的估算，非板载实测**；eig 在 A7 上的实际效率依赖编译器与实现质量，存在 ±2× 不确定性。但即使 ×10 高估，黎曼推理仍在实时余量内（2s 窗口 → 50ms 预算，实测对照 50.5ms），**计算量不是黎曼路线的瓶颈——精度才是**。

### 5.5 端侧结论

黎曼管线在端侧是"更轻、更简单、更快"的方案（估算 1~4ms vs 实测 50.5ms），但 cross-session 四分类精度 47.45% 比 LIF-EEG-TCNet 低 **16.1pp**，直接替换会显著劣化产品体验。**端侧优势无法弥补精度劣势**——维持 DL 路线（LIF-EEG-TCNet）为芯片主方案。

## 6. 结论与展望

1. **经典黎曼基线在本协议下被 DL 显著超越**：47.45% vs 63.58%（+16.1pp）。这是协议（cross-session + 跨受试池化）与信息类型（空间二阶统计 vs 时域动态 + 非线性深度特征）双重作用的结果，非调参问题（网格 8 组 + 3 参考点全部落在 42.6~47.5%）。
2. **黎曼路线作为对照的价值**：为论文提供"经典方法上界"的诚实参照；其确定性强（无 seed 波动）、实现透明（纯 numpy 可复现）、端侧极轻。
3. **可提升方向（不在本次范围，若后续需要可扩展）**：① 多频段滤波器组黎曼（FBCSP 式，每频段协方差拼接，文献可 +8~15pp，是缩小差距的主流手段）；② Ledoit-Wolf 数据驱动最优收缩（替代手调 α）；③ 最小距离均值（MDM）分类器（更经典的黎曼端侧选择）；④ within-subject 协议下重测（预期黎曼差距缩小，但 DL 同样受益）。
4. **对芯片方案的决策含义**：保持 LIF-EEG-TCNet 作为主模型；黎曼管线的 C 实现可作为低算力备胎存档，但当前精度下不建议产品化。
