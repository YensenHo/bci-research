# 真实 HBC 可行性验证总结（RV1106 硬件能力 + 板载实测）

> 验证目标：RV1106 能否自己发射/接收人体信道信号（把 HBC 从「仿真 46.3dB」推向「真实人体通信」）。
> 结论先行：**可行**——PWM 1MHz 载波、ADC 接收采样、GPIO bit-bang 发射全部板载验证通过，剩物理接线 + 真实人体实验（用户手动）。

## 1. 硬件能力查证（文档 + 设备树 + 源码）

| 外设 | 能力 | 对 HBC 的意义 |
|---|---|---|
| **PWM** | 12 控制器仅 pwm1 使能；时钟实测 **100MHz**（clk_pwm0_peri=100000000） | 理论最高输出 100MHz，**1MHz 载波完全可行** |
| **SARADC** | 2ch × 10bit，vref=1.8V（1.7578mV/LSB），转换 clk 1MHz（单次 ~44µs） | 接收采样可行（采包络后 18kSPS 足够） |
| **GPIO** | /dev/mem 直接操作 GPIO bank 可用；v2 寄存器布局（DDR_L=0x08/DR_L=0x00） | 备用发射/检测方案 |

## 2. 板载实测（真实 adb，板 5caaa04f9cdb6ba2）

| 测试 | 实测结果 |
|---|---|
| **ADC sysfs 采样** | 1000 次/55.4ms = **18.05 kSPS**；ch1 浮空均值 508.9 LSB ≈ 894.6mV、std 19.6 LSB ≈ 34.4mV；ch0 恒 1023（被 adc-keys 占用） |
| **ADC 寄存器直读** | 523µs/次（1.91kSPS），前几发转换超时 → 收端用 **sysfs 更稳** |
| **GPIO 整字写翻转** | **9.98MHz**（读改写 1.07MHz、单写吞吐 19.9M/s）→ 1MHz bit-bang 勉强可行 |
| **GPIO 寄存器布局** | 实测确认 RV1106 是 v2 布局（DDR_L=0x08、DR_L=0x00），原 0x04 代码无效 → 已修正 |
| **PWM 配置** | sysfs 100MHz 时钟 + period=100 → 1MHz 方波配置成功；踩坑已记录（enable 后改 period 返 EBUSY，正确顺序 disable→duty=1→period→duty→enable） |

## 3. 固件限制（诚实标注）

1. **pwm1 引脚固定**：本固件仅启用 pwm1（mux 固定 gpio3-27 背光引脚，无 PWM1_M0 备选），**默认不在排针**——要排针输出需改 dts 重刷固件，或改用 GPIO bit-bang 发射（引脚自由）。
2. **backlight 占用**：pwm1 被背光占用，需先释放（run_pwm_test.sh 已写）。
3. **ADC 超压**：PWM 3.3V 直连 ADC（1.8V 满量程）会超压，须 10k/4.7k 分压。
4. **原理图未确认**：PWM/ADC 引脚的排针物理位置需 Luckfox Pico Ultra 原理图（下载被断流，未完成）——接线时以官方排针图为准。

## 4. 方案要点（详见 `真实HBC最小实验方案.md`）

- **发射**：PWM 1MHz OOK（或 GPIO bit-bang 备用），符号率 1kbps（ADC 18kSPS → 每符号 ~18 采样）。
- **接收**：电极 → LM358 差分放大（50×）→ 1N4148 包络检波 → 分压 → ADC ch1 → 软件滑动窗口阈值解调。
- **帧格式**：前导码 + 8bit 量化 logits + CRC8（复用现有量化链路）。
- **三步走**：板内自发自收（分压直连）→ 两板人体（实测损耗对比 46.3dB）→ 接 LIF-EEG-TCNet 解码闭环。

## 5. 下一步（用户动手清单）

1. **买元件**（¥30 内）：Ag/AgCl 电极贴片、LM358、1N4148、电阻电容、面包板跳线（清单见方案文档 §1）。
2. **板内自发自收**：按方案 Step 1，释放 backlight + PWM 输出 + 分压短接 ADC ch1（或 GPIO bit-bang 发射），跑通"自己发自己收"。
3. **两板人体实验**：按方案 Step 2，电极贴小臂/手掌，测真实损耗 dB、对比仿真 46.3dB。
4. **完整闭环**：按方案 Step 3，发射板解码 + OOK 发射，接收板解调 + 收端解码，报经真实 HBC 的精度。

## 6. 诚实边界

- 软件链路（PWM 配置 + ADC 采样 + GPIO 翻转）已板载验证；**物理接线 + 真实人体实验未做**（需用户手动，方案已完整可执行）。
- ADC 18kSPS 限制符号率 ≤5kbps（建议 1kbps）——比仿真闭环的"8bit×11000 样本"慢，但这是真实信道的物理约束；后续可用 GPIO 输入检测提升。
- 固件 PWM 引脚限制可用 GPIO bit-bang 绕过（实测 9.98MHz 翻转）。
