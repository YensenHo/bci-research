# 真实 HBC 最小实验方案（RV1106 自发自收 + 真实人体信道）

> 目标：用 RV1106 自己发射/接收人体信道信号（不靠函数发生器/示波器），把 HBC 从「仿真 46.3dB」推向「真实人体通信」。
> 可行性已板载验证（见 `可行性验证总结.md`）：PWM 时钟 100MHz（1MHz 载波可行）、ADC 18kSPS、GPIO 翻转 9.98MHz。

## 2. 发射方案（发射板）

- **载波**：PWM1 输出 **1MHz 方波**（时钟 100MHz 实测可行，period=100）。
- **调制**：OOK（数据位=载波有无）——1 bit 1 = 1MHz 载波开，1 bit 0 = 载波关。
- **符号率建议**：接收端 ADC 实测 **18kSPS**，建议符号率 **1kbps**（每符号 ~18 采样，够软件判位；5kbps 为极限，每符号 ~3.6 采样）。
- **电极贴法**：发射电极贴小臂内侧（信号注入），参考电极贴同臂外侧或手腕（回路）。两电极差分注入人体。
- **硬件**：PWM 输出（背光引脚 GPIO3_PD3，需先释放 backlight 占用，见 run_pwm_test.sh）→ 电极。

## 3. 接收方案（接收板）

```
接收电极 ─→ LM358 差分放大（增益 ~50×）──→ 1N4148 包络检波 ──→ 0.1µF 滤波 ──→ 分压(10k/4.7k, 3.3V→<1.8V) ──→ ADC ch1
```

- **放大**：LM358 差分放大（两电极输入，放大 ~50×），把 mV 级信号提到百 mV 级。
- **包络检波**：1N4148 + 电容，把 1MHz 载波整流成基带包络（ADC 只需采包络，18kSPS 足够）。
- **分压**：放大后信号可能超 ADC 1.8V 满量程，10k/4.7k 分压保护。
- **采样**：RV1106 SARADC ch1（GPIO4_C1，空闲可用），sysfs 读（实测 18.05kSPS，比寄存器直读 1.9kSPS 稳定）。
- **软件解调**：滑动窗口阈值——窗口均值 > 阈值 = bit 1，< 阈值 = bit 0；阈值取收发双方校准（无信号时噪声底 + 余量）。

## 4. 帧格式（复用现有 8bit 量化链路）

```
[前导码 0x55 0xAA 0x55] [帧长 1B] [8bit 量化 logits 数据 N×1B] [CRC8 1B]
```

- 发射内容 = 现有 LIF-EEG-TCNet 解码的 8bit 量化 logits（与 lif_surrogate_fusion 的量化一致，±4 范围 8bit）。
- CRC8 校验收端，错帧丢弃。

## 5. 实验步骤（三步走）

**Step 1：板内自发自收（不接人体）**
- 释放 backlight → PWM1 输出已知 1MHz on/off 序列 → 分压（10k/4.7k）直连 ADC ch1（跳线短接）→ 采样 + 软件判位 → 对比发送序列报误码。
- 目标：软件链路（发→收→解调）板上跑通，误码 <1%。

**Step 2：加人体（两板，发射板 + 接收板）**
- 发射板 PWM → 电极贴小臂；接收板电极贴手掌/大臂 → LM358 放大 → 检波 → ADC。
- 测接收幅度（mV 级预期）、算实测损耗 dB（对比仿真 46.3dB）、扫距离（5/10/15cm）。

**Step 3：接解码（完整闭环）**
- 发射板跑 LIF-EEG-TCNet 解码 → 8bit 量化 → OOK 发射；
- 接收板解调 → 反量化 → 收端 LIF-EEG-TCNet 解码 → 报直连 vs 经真实 HBC 精度（对比仿真闭环的 McNemar 零损失）。

## 6. 预期与风险（诚实）

| 项 | 预期 | 风险/应对 |
|---|---|---|
| 接收信号幅度 | mV~百 mV（46.3dB 损耗 → 1MHz 1V 发射 → ~5mV 接收，需放大 50×） | 放大后噪声；用差分放大抑制共模 |
| 噪声 | 浮空 ADC 噪声实测 34mV；放大后可能更高 | 软件阈值 + 滑动平均；符号率降到 1kbps |
| ADC 精度 | 10bit/1.8V，~1.76mV/LSB | 对包络检测够用（只需区分有/无载波） |
| 人体接地/共模 | 人体是浮空天线，50Hz 工频共模大 | 差分放大 + 参考电极 |
| 1MHz 衰减 | 体表 1MHz 衰减比低频小（EQS 高频更优） | 若损耗过大，试降载波到 500kHz 或升到 2MHz |
| 固件限制 | PWM1 引脚固定背光位，不在排针 | 改 dts 重刷固件，或用 GPIO bit-bang（实测 9.98MHz 翻转可行） |

## 7. 替代方案（若 PWM 引脚接线受限）

- **GPIO bit-bang 发射**：实测整字写翻转 9.98MHz，用空闲 GPIO（如 gpio1 bank）输出 1MHz 方波序列——不需要改 dts，且引脚位置自由。
- **GPIO 输入检测**：若 ADC 18kSPS 不够，可用 GPIO 输入捕获包络边沿（GPIO 检测远快于 1MHz）。
