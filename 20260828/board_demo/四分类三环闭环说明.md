# 四分类三环闭环板载 Demo 说明（类脑 LIF-EEGNet + BCI + HBC）

把四分类 LIF-EEGNet（surrogate 发放率版，22ch，4 类）整合进 HBC 人体信道闭环，
在 RV1106 端侧芯片上跑「类脑解码 → 脑电 → 人体信道 → 收端再解码」完整三环闭环。

- **交付目录**：`~/BCI/20260828/board_demo/`
- **解码器**：`lif_surrogate_infer_4class.c`（22ch 四分类，纯 C 复刻 surrogate LIF-EEGNet，thr=1.0 / decay=0.6065 / T=8，LIF 在 pool 前，输出发放率）
- **四分类标签映射**：`{0=左手, 1=右手, 2=双脚, 3=舌头}`（与 `preprocess_4class.py` 第 9 行一致）
- **数据**：`lif_4class_test_full.bin`（int32 N=2592 + 每试次 float32×11000（22ch×500 通道优先）+ int32 label 0~3）

---

## 一、三环闭环结构（每试次，全量真实脑电）

```
环1·类脑：LIF-EEGNet（surrogate 发放率版，脉冲类脑模型）做脑电解码
环2·BCI ：读真实脑电 (22ch × 500, BCIC IV 2a 四分类评估集) 直连解码 → pred_d
环3·HBC ：量化 8bit → 逐 bit OOK 调制(1MHz EQS 载波) → 体表信道
           (IT'IS 4-Cole-Cole 色散 + AWGN) → 包络解调 → 反量化重建
收端再用 LIF-EEGNet 解码 → pred_h，对比「直连 vs 经 HBC」
```

证明：端侧芯片 RV1106 上，真实脑电经 HBC 人体信道传输后，由类脑解码器（四分类）
得到的准确率不下降（≈直连，McNemar 不显著）。

2. 数据读取：`N=2592`、每试次 `11000` float32、label `0~3`（`#define NCH 22`、`NSAMP=11000`）；

## 五、结果汇总

| 指标 | 值 |
|---|---|
| 直连解码准确率（LIF-EEGNet 四分类） | **56.8673%（1474/2592）** |
| 经 HBC 解码准确率 | **57.1373%（1481/2592）** |
| 两者一致率 | **97.8395%（2536/2592）** |
| 准确率变化（经HBC − 直连） | +0.27pp |
| McNemar | b=17 / c=24 → χ²=1.195, **p≈0.27 不显著**（连续性校正 p≈0.35） |

**直连 56.8673% 与 Python `train_4class.py` 的 final test 56.87% 逐试次一致**（1474/2592），
四分类 LIF-EEGNet 板上移植正确。

## 七、McNemar 配对显著性

直连 vs 经 HBC 同一试次配对（b=直连对/HBC错=17，c=直连错/HBC对=24）：

```python
import scipy.stats as st
b, c = 17, 24
print("无校正:", st.chi2.sf((b-c)**2/(b+c), df=1))        # χ²=1.195, p=0.2743
print("连续性校正:", st.chi2.sf((abs(b-c)-1)**2/(b+c), df=1))  # χ²=0.878, p=0.3488
```

两口径均 p≫0.05 → 经 HBC 传输**未显著改变**解码准确率 → 三环闭环成立。
（经 HBC 精度 57.14% 略高于直连 56.87%，是量化噪声偶发翻转所致，c=24 > b=17，
统计学上不显著，属采样噪声而非 HBC「增益」。）

## 八、结论

端侧芯片 RV1106 上，四分类类脑解码（LIF-EEGNet 22ch）+ 脑电解码（BCI）+ 人体信道
传输（HBC）三环闭环跑通：直连 56.87% vs 经 HBC 57.14%（Δ+0.27pp，McNemar 不显著），
一致率 97.84%，BER 3.11e-07，单次前向 49.823 ms、平均单窗口 135.3 ms（板载 A7）。
经 HBC 人体信道传输后解码准确率不下降，三环闭环成立。

> 注：板载与宿主机交叉验证**逐位一致**（同一 LCG 种子，double 噪声路径 bit-exact，
> 直连/经HBC/每类精度/McNemar/BER 全部相同），仅耗时不同（板载 A7 无硬浮点 double，慢 ~16×）。
