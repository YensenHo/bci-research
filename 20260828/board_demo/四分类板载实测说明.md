## 2. 关键语义（与二分类版完全一致，仅通道数/类别数变化）

本轮上板的 `lif_surrogate_infer_4class.c` 严格复刻 `algorithm/lif_eegnet.py` 的
`LIFActivation.forward` 语义，与二分类 `lif_surrogate_infer.c` 的唯一区别是
**22 通道 + 四分类**：

| 语义 | 二分类 8ch（上轮） | 本轮四分类 22ch |
|---|---|---|
| EEGNET_N_CH | 8 | **22** |
| SNN_N_CLASSES | 2 | **4** |
| depthwise 卷积核 | (8,1) | **(22,1)** |
| fc 读出 | (2,240) | **(4,240)** |
| LIF 位置 | pool 前 | pool 前（不变） |
| decay | 0.6065（exp(-1/tau)，tau=2.0） | 0.6065（不变） |
| thr | 1.0 | 1.0（不变） |
| timesteps | 8 | 8（不变） |
| 输出 | 发放率 sum(spk)/T | 发放率（不变） |

LIF 逐元素语义（C 代码 `lif_rate()`）：
```
mem = 0
for s in 0..7:
    mem = decay * mem + x        # x = 卷积+BN 后的恒定电流（每步相同）
    spk = (mem > thr)            # 严格 >，与 SurrogateStep.forward 的 (x>0) 一致
    if spk: mem = 0              # 硬重置
rate = spike_count / 8           # 发放率
```

结构（折叠 BN，与二分类版一致）：
```
conv1(1→8, 1×63, pad L31/R31)[fold bn1] → depthwise(8→16, 22×1, groups8)[fold bn2]
→ LIF(thr1,decay) → AvgPool(1,4) → sep_depthwise(16→16, 1×15, pad L7/R7)[无BN]
→ pointwise(16→16)[fold bn3] → LIF(thr2,decay) → AvgPool(1,8) → FC(240→4)
```

折叠进 `conv1+bn1`、`depthwise+bn2`、`pointwise+bn3`；`sep_depthwise`/`fc` 无 BN 原样复制。

## 4. 宿主机 C vs PyTorch 逐位一致验证

### 4.1 严格逐位（numpy float32 + C 顺序参考，`-ffp-contract=off`）

```
$ verify_bit_exact_4class.py --n 5
[权重] decay=0.606530666, thr=1.0, timesteps=8, n_classes=4
[参考] 逐样本 numpy(float32, C 顺序) 前向 ...
[对比] numpy(C 顺序) vs C  max|diff| = 0.000e+00
[对比] 逐位完全一致的样本数   : 5/5
✓ 严格逐位一致：C 移植与 float32 C-顺序参考完全一致（0 误差）
```

**结论：C 移植与「同一累加顺序的 float32 参考」0 误差，结构性正确（含 depthwise (22,1)
核索引 + 4 类 FC 布局）。**

### 4.2 与 PyTorch 折叠参考（`verify_lif_surrogate_c_4class.py --mode host`）

```
$ verify_lif_surrogate_c_4class.py --n 2592 --mode host
[PyTorch] n_classes=4, timesteps=8, thr=1.0, tau=2.0
[BN 折叠] 折叠参考 vs 原模型  logits max|diff| = 1.84e-02
[对比] C vs PyTorch logits 最大绝对误差 : 8.66e-03
[对比] 预测一致率          : 2592/2592 (100.0%)
[精度] PyTorch 折叠参考   : 56.87% | C : 56.87%
✓ C-SNN 与 PyTorch-SNN 预测完全一致（22ch 四分类移植正确）
```

**诚实说明**：全量 2592 下 C 与 PyTorch 的 logits 最大绝对误差是 8.66e-03（非 1e-5），
「BN 折叠 vs 原模型」是 1.84e-02。根因与二分类版 §4.2 完全一致，**非移植 bug**：

- PyTorch `conv2d` 用优化内核，累加顺序与 C 朴素循环不同，浮点非结合性使 pre-LIF 电流
  差 ~1e-6；BN 折叠（`W·scale` 先乘再卷积）也改变算术顺序，引入同量级差异。
- LIF 阈值是**不连续阶跃**：膜电位恰在 thr=1.0 附近的元素，其发放决策会被这 ~1e-6 的
  差异翻转，logits 因此跳 ~1e-2。但**没有任何一个翻转改变 argmax 预测**（2592/2592 一致，
  精度 56.87% 完全一致）。
- §4.1 已证明 C 移植逻辑 0 误差；预测一致率 100% 是正确性门槛。

## 7. 板载性能

- 单次前向：**49.747 ms**（RV1106 Cortex-A7 @ 1.2 GHz，静态 musl 二进制）
- 全量 2592 试次：128.94 s
- 对比二分类 8ch 上轮：23.434 ms → 本轮 22ch 四分类 49.747 ms（约 2.1×，主因是
  depthwise 22 通道求和 + 4 类 FC 的额外乘加）。
- 纯 C 朴素循环实现，未做任何 NEON/定点/循环展开优化；发放率版 LIF 只需 8 步、
  每步只做一次乘加，理论上还有较大加速空间。

## 8. 精度诚实性声明

- 本报告所有精度均为真实训练产物 + 真实板载运行输出，**未虚构、未挑种子**。
- 四分类 22ch 绝对精度偏低（56.87%）是**协议难度所致**：cross-session + subject-independent
  （T 会话训练 → E 会话测试，单模型跨 9 受试），本身比文献 EEGNet 四分类 70~75%
  （多为 within-subject / LOOCV）更难，故 EEGNet ELU 基线也只有 58.29%。这是训练阶段的
  已知结论（见 `对比报告_四分类22ch_类脑化零代价验证.md`），**非板载部署引入**。
- 本部署验证的科学结论是 **ANN 权重 → 板载 C 推理的无损迁移**（0.00 pp），该结论不受
  绝对精度高低影响。
