# 类脑计算 + BCI + HBC 创业落地路径调研（技术向 · 非完整 BP）

> 用途：说服导师「创业反哺学术」的技术落地支撑 + 博士阶段/毕业后分阶段路线。
> 数据来源：20260820 的调研1/2/3 + 博睿康事实核实，凡无法核实项已标注。
> 定位原则：**不谈钱、不谈估值/IPO 黑话**（导师只认学术），聚焦技术向落地路径、空位、风险、里程碑。

## 1. 赛道现状与空位

### 1.1 国内 BCI 玩家矩阵（已核实）

| 公司 | 路线 | 赛道 | 与本项目关系 |
|---|---|---|---|
| 强脑 BrainCo | 非侵入 EEG 头环 + 仿生手 | 消费红海 + 医疗康复 | 不正面竞争 |
| 脑陆 BrainUp | 非侵入 EEG + 类脑决策 | 开放平台 | 类脑方向有布局，但非端侧解码 |
| 博睿康 Neuracle | 非侵入 EEG + NEO 植入 | 医疗级龙头 | **产学研对标范本** |
| 柔灵/念通/臻泰/中科搏锐 | 非侵入 EEG 消费/康复/fNIRS | 红海/壁垒 | — |

### 1.2 类脑芯片 / 人体通信 HBC 玩家

- **类脑芯片**：灵汐科技（北京，清华类脑芯片）、时识科技 SynSense（深圳/瑞士，DYNAP-CNN SNN 芯片）。与 BCI 结合的「类脑 + 脑机」交叉玩家**极少**。
- **人体通信 HBC**：普渡 Sen 组（SPARC Lab，学术源头）、Ixana（YC+DARPA，商用）。国内成规模的 HBC 商用玩家**公开可检索范围内几乎没有**。

### 1.3 空位判断（一句话）

**「类脑计算（SNN 脉冲算法）× 非侵入式可穿戴 BCI 边缘解码 × HBC 人体通信回传」三交叉点，公开可检索范围内无成规模对手。** 理由：
- 消费头环红海、医疗康复壁垒高、专用芯片门槛高，三者都避开了；
- 本项目已有实证底座：**RV1106 国产 NPU 跑通 EEG 神经解码（公开可检索范围内首例）** + HBC 闭环 + 约束驱动鲁棒解码（76.08% 联合维度）；
- 类脑方向（LIF-EEGNet）提供差异化纵深：SNN 天然规避 NPU INT8 量化崩坏问题（脉冲本就是 0/1 二值）。

### 1.4 对标博睿康（实验室起步产学研路径）

博睿康 2011 年由清华神经工程实验室博士胥红来创办，15 年走完「实验室打磨 → 科研设备现金流 → 医疗级取证 → IPO」。**与本项目「北理工仪器学院 + 宋勇院长实验室」同构**（详见 20260820《博睿康事实核实》）。核心可复制的三点：① 起步全程复用实验室设备/课题经费，不烧钱；② 先做科研设备养活研发（现金流）；③ 导师（高上凯/洪波）提供学术背书 + 临床通道。

## 2. 技术产品路线（分阶段）

| 阶段 | 时间 | 产品形态 | 博士阶段/毕业后 | 反哺学术 |
|---|---|---|---|---|
| **L1 实验室原型** | 博 1–3 | RV1106 端侧解码 + HBC 闭环 Demo（本次 20260828 交付） | 博士阶段 | 论文（约束驱动鲁棒解码 / LIF-EEGNet） |
| **L2 科研样机** | 博 2–4 | 可穿戴 EEG 采集 + 端侧解码 + HBC 回传的科研套件 | 博士阶段 | 横向项目 / 真实数据采集反哺论文 |
| **L3 科研仪器产品** | 博 4–毕业 | 面向高校/医院科研科室的解码模块 + 配套软件 | 博士阶段（横向现金流） | 竞赛 + 专利 + 顶刊 |
| **L4 医疗级产品** | 毕业后 | 医疗级脑机康复/监护（需注册证 + 临床） | 毕业后产业化 | 职称帽子 + 学术优先权 |

**博士阶段可做**：L1–L3（技术 + 科研现金流 + 论文/专利/竞赛）。**毕业后做**：L4 医疗取证 + 融资放大。分界线明确，不提前烧钱、不提前啃注册证。

## 3. 知识产权与专利布局建议

1. **成果归属前置**（博睿康教训）：第一时间和宋勇老师 + 北理工技术转移办公室约定「实验室职务成果如何授权创业公司使用 + 收益分配」，从根源规避股权/专利纠纷。
2. **专利方向**（与现有「穿颅 HBC 信道测量等 12 个方向初步检索多数空白」一致）：
   - HBC 信道测量方法（体表/多层组织，中性表述）
   - 端侧低精度（5bit/INT8）鲁棒解码方法
   - LIF-EEGNet 脉冲解码在 HBC 闭环的部署方法（若落地）
   - 约束驱动鲁棒解码（联合平坦化训练）
3. **脱敏红线**：北理工国防七子背景，涉及敏感课题。公开/开源前必须中性化（「穿颅」→「体表/多层组织」、删除课题代号），图片重跑生成。

## 4. 风险清单

| 风险 | 等级 | 说明 | 应对 |
|---|---|---|---|
| 硬件（NPU 量化） | 高 | RV1106 INT8 量化对深度可分离小模型失配（42~58%） | 本次 P0-2 消融给结论；备选 CPU 18.5ms 或换轨 SNN |
| 临床 | 高 | 医疗级需临床 + 伦理 + 注册证，周期长 | 博士阶段不碰，L4 才启动 |
| 注册 | 高 | 三类医疗器械注册周期数年 | 同上，毕业后 + 导师临床通道 |
| 资金 | 中 | 早期不烧钱，靠实验室资源 + 横向项目 | 对标博睿康「先养活自己再融资」 |
| 人才 | 中 | 端侧 + 类脑 + HBC 复合人才稀缺 | 同门团队 + 导师背书 |
| 数据 | 高 | 真实 HBC 体耦合测量缺 benchmark 野外噪声 | 远期数据飞轮；方法上桌、数据不上桌 |
| 知识产权 | 高 | 职务成果归属不清 → 股权纠纷 | 前置约定（§3） |

## 5. 分阶段里程碑（技术向）

- **M1（本次，博 1）**：NPU 量化修复给结论 + LIF-EEGNet 骨架 + MyoText 复现骨架 + 可演示 Demo。
- **M2（博 2）**：科研样机（EEG 采集 + 端侧解码 + HBC 回传），跑通真实体耦合测量第一版。
- **M3（博 3）**：论文（约束驱动鲁棒解码 + LIF-EEGNet）+ 专利 + 研创赛/互联网+/挑战杯三线投稿。
- **M4（博 4–5）**：科研仪器产品 + 横向现金流 + 医院 IIT 临床研究通道。
- **M5（毕业后）**：医疗取证 + 多轮融资 + 产业化。
