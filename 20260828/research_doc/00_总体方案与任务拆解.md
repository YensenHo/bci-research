- **换 SOTA 解码器（MIRepNet/EEG-Conformer）**：8ch 小数据 MI 二分类下 EEGNet 最优，不换。

## 2. 顶层方针对齐（类脑计算 + BCI + HBC）

三条硬约束，每个技术任务都要过一遍「是否对齐」：

1. **算法层面**：模型不写死为普通 CNN，激活层可配置（现有 `eegnet.py` 已支持 `activation=elu/relu`），预留替换为 LIF 脉冲神经元的接口。
2. **部署层面**：NPU 改造、板载部署都服务于「类脑 + BCI + HBC」体系——NPU 量化问题本质是「脉冲类脑模型在未来 NPU/SNN 芯片上同样要面对的低精度推理问题」的提前预演。
3. **Demo 层面**：最终产出可演示的端侧-回传-上位机 Demo，作为整套体系的验证载体，并写明「如何替换为 LIF-EEGNet」的路径。

**对齐的一句话表述**：本项目的科学问题不是「再做一个 EEG 解码模型」，而是「在 HBC 人体通信闭环 + 国产端侧低精度算力的双重约束下，如何系统求解精度-鲁棒性-功耗三难，并为后续切换 SNN 脉冲类脑模型预留路径」。

## 3. 关键判断（任务清单与现状的 3 处对齐修正）

### 3.1 P0-1「自监督 MaskedEEGNet」→ 重定义为「约束驱动鲁棒解码深化 + LIF 演进」

任务清单 P0-1 写「在 MaskedEEGNet 自监督骨架基础上优化」，但该骨架**不存在**（§1.2 已证伪）。修正为：

- **主任务**：在已验证的联合平坦化（--hbc-aug --quant-aug）基础上深化扰动建模——更真实的 HBC 噪声分布（当前是 AWGN σ/H 标量，可升级为含突发/脉冲噪声的信道模型）、更细的 SNR 分档、以及「5bit 量化 + 信道噪声」联合扰动的更严格消融。
- **LIF 演进任务**（顶层方针）：设计 LIF-EEGNet 的 ANN-to-SNN 转换路线——EEGNet 的 ELU/ReLU 替换为 LIF，训练代理 ANN（用可导 LIF 或 clamp 近似）→ 转 SNN 推理，评估精度损失与功耗收益。先出**路线文档 + 代码骨架**，不追求一步到位。
- **约束**：所有模型定义保留 `activation` 可配置接口，不写死 ELU。

### 3.2 P0-2「NPU 量化修复」→ 现实边界明确，消融 + 如实写结论

- 已确认：rv1106 的 NPU **只支持 INT8**（w8a16/int16/FP16 均报「not support」，见 `convert_rknn.py` 注释）。这意味着「混合量化」的可用空间很窄——rv1106 上 FP16 层无法走 NPU，只能回退 CPU，混合量化意义有限。
- **真正值得试的是 QAT（量化感知训练）**：在 PyTorch 侧用 fake-quant 训练，让模型适应 INT8 量化噪声，再导出 RKNN。这是「约束驱动鲁棒解码」在权重/激活量化维度的自然延伸（与 §3.1 的 --quant-aug 思路同源，但 QAT 是更严格的训练时量化模拟）。
- **消融实验**：PTQ（已证伪）vs QAT vs 混合量化（若工具链支持）三组，记录 logits 对齐度 / argmax 一致率 / 准确率 / 耗时。
- **硬边界**：rknn-toolkit2 只在 Linux x86_64 可跑，当前 Mac 无法直接转 RKNN。产出：① PyTorch 侧 QAT 训练脚本（本机可跑，先验证「QAT 能否把 INT8 精度救回来」）② RKNN 转换脚本 + Docker/Linux 执行说明。若 QAT 在 PyTorch fake-quant 层面都救不回精度，则明确结论「RV1106 NPU 对 EEGNet 这类小模型深度可分离卷积的 INT8 量化是工具链固有限制，NPU 线维持关闭，CPU 18.5ms 为正式方案」——**这是真实结论，不强行编「修复成功」**。

### 3.3 P1「MyoText 复现」→ 服务体系，预留 SNN 接口

- MyoText 无官方开源代码（任务清单已明确），从零复现。手指分类网络预留替换为 SNN 脉冲版本的接口。
- 严格遵循 split-execution：轻量手指分类（CNN-BiLSTM-Attention）目标部署 RV1106（优先 NPU，不可用回退 CPU），T5 卸载上位机。
- 明确记录复现指标 vs 原论文差距 + 局限。

## 4. 分任务方案

### P0-1 约束驱动鲁棒解码深化 + LIF 演进（algorithm/）

**P0-1a 鲁棒解码深化**（复用 `luckfox-deploy/model/train.py` 的 --hbc-aug/--quant-aug）：
1. 升级 HBC 噪声模型：从标量 AWGN → 复用 `hbc-bci-sim/sim/noise.py` 的信道噪声 + 突发噪声脉冲，注入训练。
2. 消融：{干净, 单域 HBC, 单域量化, 联合} × {基线, 噪声增强, 量化增强, 联合平坦化}，补齐 SNR 分档下的鲁棒性曲线。
3. 输出：可训练完整脚本 + 消融报告（暗色图，对齐 PPT 配色）。

**P0-1b LIF-EEGNet 演进路线 + 代码骨架**：
1. 出 `LIF-EEGNet 演进路线.md`：ANN-to-SNN 转换（ELU/ReLU→LIF）、可导 LIF（如 LIF 的 surrogate gradient）、训练代理 ANN → 转 SNN 推理、精度/功耗评估方案。
2. 代码骨架：`lif_eegnet.py`（EEGNet 激活层替换为 LIF，保留 activation 接口），先跑通前向 + 与 EEGNet 对齐基线，不追求立即上板。

### P0-2 NPU 量化修复消融（rknn_npu_fix/）

1. `qat_train.py`：PyTorch fake-quant 量化感知训练（torch.ao.quantization 或自写 fake-quant），验证「QAT 后 INT8 精度能否接近浮点」。
2. `hybrid_quant_convert.py`：RKNN 混合量化转换脚本（标注 rv1106 混合精度支持边界）。
3. 消融对比：PTQ / QAT / 混合量化 → 输出对比报告 `NPU量化修复对比报告.md`，明确结论 + 工程替代方案。

### P0-3 板载部署 + Demo（board_demo/）

1. 整合优化后模型 → 部署 RV1106 → 复用 HBC 闭环测试（McNemar/SNR 瀑布/延迟/内存）。
2. 小型可演示 Demo：端侧解码 + HBC 仿真回传 + 上位机可视化，输出运行脚本 + 使用说明。
3. `Demo替换LIF-EEGNet说明.md`：如何在此 Demo 上替换为脉冲类脑模型。

### P1 MyoText 分层解码复现（algorithm/myo_text/）

1. `finger_classifier.py`（CNN-BiLSTM-Attention，预留 SNN 接口）
2. `qwerty_mapping.py`（QWERTY 指法候选字母映射）
3. `t5_reconstruct.py`（T5 句子重建，上位机）
4. 复现实验报告 + 融入「类脑+BCI+HBC」体系说明 + SNN 替换路径。
