# 类脑计算 + HBC + BCI 三者结合统一架构（行动纲领 · 顶层蓝图）

> 这是整个项目唯一的行动纲领。芯片 Demo、板载部署、算法演进、创业路径，全部是这条纲领的载体。
> 本文回答一个最根本的问题：**为什么是这三者？它们凭什么不是拼凑，而是物理上的一体？**

---

## 0. 纲领一句话

**「稀疏的脑信号 → 稀疏的类脑计算 → 稀疏的人体传输」，三者共享同一个物理本质——稀疏性，因此它们是一个系统的三个层面，不是三个拼盘。**

---

## 1. 三者的角色

| 层面 | 角色 | 载体 |
|---|---|---|
| **BCI（脑机接口）** | 感知层：脑电/肌电的采集与解码 | EEGNet / MyoText 手指分类 |
| **类脑计算（SNN/LIF）** | 计算层：脉冲神经网络的低功耗解码 | LIF-EEGNet |
| **HBC（人体通信）** | 传输层：以人体为信道，低带宽回传 | 体表耦合信道（46.3dB/5bit） |

闭环：**感知(BCI) → 计算(类脑SNN) → 传输(HBC) → 执行器**，再回到感知。

---

## 2. 为什么是这三者（物理互补，不是拼凑）

三者在「稀疏 / 低功耗 / 低带宽」这个物理维度上**同构**，因此两两之间都有硬耦合：

### 2.1 类脑 SNN ↔ HBC：脉冲就是信道要传的东西
- SNN 输出是 **0/1 稀疏脉冲序列**，而 HBC 是**低带宽体表信道**（5bit 即保精度，比 8bit 省 37.5%）。
- 脉冲序列本身**就是最适合 HBC 传输的载荷**——不用把浮点特征硬塞进窄信道。
- 反过来：HBC 的带宽约束**恰好逼出 SNN**（稀疏脉冲），而不是逼出高带宽连续浮点。二者互为因果。

### 2.2 HBC ↔ BCI：可穿戴形态 + 约束逼出新问题
- BCI 要可穿戴（电极贴头皮），HBC 用**人体本身做信道**（不需要射频天线/有线），天然匹配可穿戴形态。
- 但 HBC 引入真实链路约束（46.3dB 损耗 + 突发/脉冲噪声）——这正是「约束驱动鲁棒解码」的来源（已验证：噪声增强后经 HBC 几乎零损失，板载 McNemar p≈0.94）。

### 2.3 类脑 SNN ↔ BCI：稀疏信号 + 低功耗 + 绕开量化 bug
- 脑电是**稀疏、非平稳、事件驱动**的信号，SNN 的事件驱动计算天然适配。
- SNN 脉冲稀疏性使 **MAC 变累加**，功耗降 10~100×，适配可穿戴 BCI 的电池约束。
- **最硬的一条**：RV1106 NPU INT8 量化崩坏（42~58%）是工具链对深度可分离小模型的 bug（P0-2 已定性），而 **SNN 的 0/1 脉冲天然规避 INT8 量化**——类脑不是「修复」NPU，是「换轨」绕开它。

## 3. 统一架构图（文字版）

```
┌─────────────────────────────────────────────────────┐
│  可穿戴端（RV1106 / 未来 SNN 芯片）                    │
│                                                      │
│  BCI 感知 ──► 类脑计算 ──► 决策                       │
│  (脑电采集)   (LIF-EEGNet    (分类标签/稀疏脉冲)       │
│               脉冲解码)                               │
│                   │                                  │
└───────────────────┼──────────────────────────────────┘
                    │ HBC 体表回传（稀疏脉冲/标签，5bit）
                    ▼
           上位机 / 执行器（T5 语言模型 / 康复设备）
```

- 关键：**回传的不是原始浮点特征，而是稀疏脉冲或分类标签**——这是类脑与 HBC 结合后，链路带宽的质变。

## 5. 对创业的映射（三交叉空位 = 护城河）

- 消费头环红海、医疗康复壁垒高、专用芯片门槛高——但「**类脑 SNN × 非侵入式 BCI × HBC 可穿戴回传**」这个三交叉点，公开可检索范围内**无成规模对手**（详见 business_plan）。
- 护城河不在模型（架构都公开可抄），在**「国产 RV1106 + 5bit + HBC 闭环 + 类脑换轨」的工艺型隐性知识**，以及远期「数据飞轮」。
- 说服导师「以创促研」的叙事就一句话：**「用类脑计算在可穿戴端做 BCI 解码、经人体信道回传」是一个能同时产论文（约束驱动鲁棒解码 / LIF-EEGNet）、专利、竞赛、产品的统一课题，三者绑定，缺一不可。**

## 6. 里程碑（三者逐步统一）

| 里程碑 | 三者结合度 | 产出 |
|---|---|---|
| M1（本次） | BCI+HBC 闭环，类脑留接口 | NPU 定性 + LIF 骨架 + Demo v1 + MyoText 骨架 |

- [ ] Demo 的回传载荷是「稀疏脉冲/标签」而非「原始浮点特征」吗？
- [ ] 创业叙事是否落在「三交叉空位」，而非单点（纯 BCI 或纯类脑）？
