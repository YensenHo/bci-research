## 三、人体通信（HBC）——诚实说明

- **无公开数据集**（领域现状：HBC 数据均为各团队自采，Sen 组不公开原始数据）——这是 HBC 与 BCI 的本质区别。
- **能上芯片的**：收发算法（OOK 已有 ✅、FSK/扩频/纠错码可加）——但没有真实信道，仿真验证意义有限。
- **结论**：HBC 方向冻结，等元件到位做真实实验（方案已交付 `board_demo/hbc_real/`，¥30）。

## 五、防坑记录（本轮实际踩到，供后续参考）

1. **arXiv API 偶发限流**（连续查询后返回空/SSL error）——用浏览器（arxiv.org/list 或搜索页）备选，或等几分钟。
2. **pip 安装受代理配置影响**（pip.conf 里配了代理但代理没开 → ProxyError）——用 `--proxy ""` 或清华镜像直连，或按预案 numpy 手写（黎曼管线就是手写的）。
3. **Python urllib 被特定服务器拒绝**（Graz ECONNREFUSED，curl 100% 成功）——下载一律用 curl。
4. **zsh 变量不分词**（`$PY cmd` 整串当命令名）——写 bash 脚本或直接写全命令（本轮第三次踩，务必遵守）。
5. **Zenodo record ID 记忆不可靠**（998318 是甲虫论文）——用 Zenodo 搜索页找，别凭记忆跳 ID。
6. 沿用既有防坑清单：search_files 中文不可靠 / smoke 先行 / 双 seed / 数据格式仔细。

## 六、结论

- **BCI 方向最肥**：2b（进行中）+ CHB-MIT + SSVEP/CCA 三个新任务/范式都数据可达、可上芯片。
- **类脑方向**：稀疏化已完成，temporal coding 是唯一的大工程候选，STDP 是可做的小原型。
- **HBC 方向**：无数据可挖，冻结等硬件。
- **方法论**：延续"同协议实测筛选"（黎曼 47.45% vs DL 63.58% 就是最新例证——试了才知道）。
