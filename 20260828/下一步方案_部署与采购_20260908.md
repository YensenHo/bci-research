# 下一步部署 + 采购方案（基于 2026.9.8 会议纪要）

> 会议纪要结论：算法层 ~90% 已就位（7 任务板载实测），物理层仅 ~30%（公开数据集 + 信道纯仿真 + CPU 模拟脉冲）。
> 最终产品不是端侧模组，是「碳硅协同检测解码系统」——戴在身上的日常脑电解码系统。
> 因此下一步核心 = **补物理层 + 补采集入口**，把「算法 demo」升级成「真系统」。

## 二、近期（3 个月）—— 芯片上需要部署的东西

按会议纪要的三处短板逐条补，P0 优先。

### P0-1 真实 HBC 信道实测（物理层第一优先，¥30 启动）

会议纪要：HBC 当前是「高斯噪声简化模拟」，缺乏说服力。

- **部署**：把 `hbc_channel.c` 里的 46.3dB 仿真增益，替换为真实体表测量值。
- **做法**：函数发生器出 1MHz 载波 → Ag/AgCl 电极贴小臂发射 → 人体 → 接收电极（间距 5/10/15cm）→ 示波器测幅度 → 算 `Loss=20log10(Vtx/Vrx)`。
- **回填**：实测损耗（预计 30~60dB）写进信道模型，让三环闭环用「实测校准过的信道」而非纯仿真。
- **验证里程碑**：实测损耗 vs 仿真 46.3dB 的差异曲线，本身就是一个论文点（「仿真 vs 实测的校正」）。

### P0-2 HBC 信道建模升级（会议纪要明确要求）

会议纪要：需引入「电路传递函数法 + 有限元仿真法」，替代高斯噪声。

- **电路传递函数法**：头→手臂物理链路抽象为等效电路（皮肤/脂肪/肌肉的 R/C 网络），基尔霍夫定律给传递函数，描述体表传输特性。
- **有限元仿真法**：分层三维模型（皮肤/脂肪/肌肉，介电常数参数），仿真信号衰减与吸收。
- **产出**：`hbc_channel_model.md`（两种建模的数学表达 + 与实测对照），作为 HBC 信道从「玩具」到「可信」的关键。

### P0-3 类脑优势验证（会议纪要明确要求，否则「类脑」立不住）

会议纪要：仅替换神经元实现类脑化，未体现相对 ANN 的独特优势。

- **部署**：补三组对比实验，证明 LIF 相对 ANN 的「独特优势」：
  1. **能效**：脉冲发放率 8~13% → 理论 MAC 数/能耗 vs ANN 全激活（已有 −43~71% 脉冲流量数据，补成能耗对照）；
  2. **时空特性**：SNN 对时序噪声/扰动的鲁棒性 vs ANN（低 SNR 下 +1.77pp 已有，补系统化）；
  3. **稀疏性**：不同发放率甜区的精度-能耗帕累托曲线。
- **验证里程碑**：一张「精度 vs 能耗」图，证明「类脑不是情怀，是板上算出来的能耗优势」。

### P1-1 脑电采集前端接入（从「公开数据集」到「真系统」的关键）

这是「模组 → 系统」的分水岭：系统必须有真实的采集入口。

- **部署**：ADS1299（或同类 AFE）采集板 → SPI → RV1106，实现「电极 → 真实脑电 → 芯片实时解码」。
- **软件**：采集驱动 + 预处理（Z-score 用整体标量，会议纪要教训）+ 实时推理管线。
- **验证里程碑**：真人戴电极，芯片实时出四分类结果（不再喂公开数据）。

### P1-2 在线校准（within-subject 精度从 63% 到 80-90% 的关键）

- 现状 63.58% 是 cross-session，离 within-subject 80~90% 差一档（会议纪要诚实承认）。
- **部署**：新用户 few-shot 校准（少量标定试次微调），把跨被试冷启动问题用校准解决。
- **验证里程碑**：同一用户 within-subject 精度到 80%+。

### P1-3 多任务切换框架（「日常系统」需要能切场景）

- 7 任务已分别实测，但「日常脑电解码系统」需要一个统一入口：睡眠监测（夜间）+ 疲劳/专注监测（白天）是日常最自然的两个主场景。
- **部署**：任务路由 + 模型热切换（睡眠模型 / 疲劳模型 / MI 模型）。

### P2 NPU 量化（结论已有，QAT 收尾）

- PTQ 已证伪（42~58%），QAT 已在 `rknn_npu_fix/` 做过（`qat_train.py`）。结论：维持 CPU 50ms 为正式方案，QAT 若也救不回就明确「工具链固有限制」，不强行编成功。

## 四、未来宏大愿景

### 4.1 市场定位：单项是红海，三环交叉是蓝海

| 赛道 | 判断 | 玩家 |
|---|---|---|
| 非侵入 EEG 消费头环 | 🔴 红海，同质化 | 强脑/柔灵/脑陆/回车密集 |
| 医疗级 BCI（植入/康复） | 🟡 壁垒高，非现在能碰 | 博睿康/脑虎/臻泰 |
| 类脑芯片 | 🟡 已被占 | 灵汐/时识 |
| HBC 人体通信 | 🟢 国内几乎空白 | 普渡 Sen 组（学术）/Ixana（海外商用） |
| **类脑 × BCI × HBC 边缘解码** | 🟢 **蓝海，公开可检索无成规模对手** | **本项目** |

**定位（一句话）**：不跟强脑抢消费头环、不跟博睿康啃医疗注册证，卡住「类脑脉冲解码 × 非侵入可穿戴脑电 × HBC 人体通信回传」这个三交叉空位——这是别人拼不出来的组合，而你已经板上实测跑通。

**差异化护城河（四条，都是板上事实）**：
1. **SNN 天然规避 NPU 量化 bug**：脉冲 0/1，INT8 崩坏对它免疫（这是把「缺点」变「优点」的独家逻辑）；
2. **HBC 隐私 + 低功耗**：数据不出身体、不发射无线电，是脑电数据最敏感的隐私场景的天然解；
3. **¥338 国产成本**：别人几万块的专用硬件，你 300 块通用 SoC 搞定；
4. **真实数据飞轮**：一旦自采 + 真实 HBC 实测，数据壁垒别人抄不走（方法上桌、数据进实验室）。

### 4.2 产品形态：从「模组」到「戴在身上的系统」

最终产品 = **碳硅协同检测解码系统**，四个组成：

```
脑电采集（电极/前端）
   → 端侧类脑解码（芯片，¥338）
   → 人体通信回传（HBC，数据不出身体）
   → 上位机/身边设备反馈
```

**主打场景（从「日常」切入，避开医疗注册证）**：
1. **睡眠监测**（夜间连续，85% 分期已实测）—— 最日常、最刚需；
2. **疲劳/专注监测**（高负荷人群：核操作员/交警/长途司机）—— 主动预警；
3. **老年健康主动养老**（24h 连续，居家）—— 老龄化最大增量。

**分阶段路线**（对齐博士节奏）：

| 阶段 | 时间 | 产品形态 | 一句话 |
|---|---|---|---|
| L1 实验室原型 | 博1（✅已达成） | RV1106 + HBC 闭环 Demo | 三环算法全部板上实测 |
| L2 科研样机 | 博2-3 | 真实 EEG 采集 + 端侧解码 + 真实 HBC 回传 | 补物理层，从仿真到实测 |
| L3 科研仪器 | 博4-毕业 | 面向高校/医院科研科室的解码模块 + 软件 | 第一笔现金流（对标博睿康） |
| L4 医疗级 | 毕业后 | 医疗级监护/康复（需注册证） | 产业化 + 融资放大 |

**博士阶段做 L1-L3（技术+论文+专利+现金流），毕业后做 L4（取证+融资）**——分界线明确，不提前烧钱、不提前啃注册证。
