## 一、芯片能做什么（板载实测，真实 adb）

**平台**：RV1106（瑞芯微通用 SoC，双核 A7 + 0.5TOPS NPU，¥338），Luckfox Pico Ultra 开发板。

| 能力 | 实测值 | 来源 |
|---|---|---|
| 四分类脑电解码（左/右/双脚/舌头，22ch） | **clean 63.58%**（cross-session 跨 9 人） | 板载 2592 试次 |
| 二分类脑电解码（左右手，8ch） | 77.70% | 板载 1296 试次 |
| 单次前向耗时 | **50.5ms**（2s 窗口 40× 余量） | 板载计时 |
| 类脑脉冲解码（LIF-EEG-TCNet） | 0/1 脉冲，零代价追平 ANN | 板载逐位一致 |
| NPU 量化 bug 规避 | 0/1 脉冲天然规避 INT8 崩坏（42~58%） | 板载对比 |
| HBC 人体信道闭环 | 经 HBC **62.35%**（Δ−0.08pp，McNemar p≈0.80 不显著） | 板载 2592 试次 |
| 鲁棒解码（8dB 信道降质） | **54.17%**（HBC 噪声增强，+14.85pp vs 无增强） | 板载 2592 试次 |
| 上位机可视化 | 一键演示完整闭环（暗色 UI，四分类） | 已接入 |

## 三、实验记录（全部真实，成功 + 负结果）

### ✅ 成功的（上板/定论）

| 实验 | 结果 | 状态 |
|---|---|---|
| EEG-TCNet 移植（世界主流轻量模型） | 四分类 +5.56pp（56.87→62.42%），配置适配短窗场景（KE=63+GAP，论文原配置反而 −1.9pp） | ✅ 上板 |
| LIF 化（surrogate 训练） | 零代价追平 ANN（二分类 77.7%、TCNet 62.42%），TCN 架构也成立 | ✅ 上板 |
| HBC 三环闭环 | 直连 vs 经 HBC McNemar 不显著（p≈0.72~0.80） | ✅ 板载 |
| HBC 噪声增强 | 8dB +14.85pp（54.17 vs 39.31%），clean 不降反升（+1.16pp） | ✅ 上板 |
| SNN 稀疏化 | 甜区 8~13% 发放率（−2.7pp，8dB 反而 +1.77pp），脉冲流量 −43~71% | ✅ 定论 |
| NPU 量化崩坏定性 | RKNN 工具链 bug（fake-quant 98.46% vs 板载 42~58%），非量化极限 | ✅ 定论 |
| 鲁棒解码（EEGNet） | 低 SNR 拐点 +3.94pp，拐点后移 ≥3.4dB | ✅ 定论 |
| 真实 HBC 可行性 | PWM 100MHz 时钟/ADC 18kSPS/GPIO 9.98MHz 全部板载验证，¥30 方案就绪 | ✅ 可行 |
| signed LIF 编码 | 负半轴代价 −1.4→−0.38pp（补回大部分） | ✅ 定论 |

### ❌ 负结果（诚实记录，同样有价值）

| 实验 | 结果 | 结论 |
|---|---|---|
| 欧氏对齐（EA） | 0 增益（−0.04~−0.19pp） | T/E 会话差异仅 1.45%，无偏移可对齐；EA 适用跨被试冷启动 |
| 通道剪枝 | 16ch −3.3~−3.6pp、12ch −5.9pp | 22ch 分布式编码无真正冗余通道（Fz 贡献最小也有 3.2pp） |
| 输入脉冲编码（delta） | 全脉冲化 −24~−34pp | 1bit delta 对 EEG 信息损失大（重构相关 0.14），输入编码是 SNN 公认难题 |
| 突发噪声增强 | null（与纯 AWGN 无差异） | 当前参数下突发域无增益 |
| ann2snn 转换路线 | 55%（−24pp） | 率编码标定坑（thr=1.0 而非 positive-max），已被 surrogate 直接训练取代 |
| RKNN 混合量化 | 无法 Mac 验证 + NPU 线关闭 | rv1106 仅 INT8，工具链 bug 无可救对象 |

## 四、世界定位（诚实）

- **单项不领先**：BCI 精度（非侵入 63.58% cross-session vs 世界 90%+ within-subject）、类脑（通用 CPU 模拟 vs Loihi/天机）、HBC（仿真 vs Sen 组实测）——差距真实存在。
- **组合有独特性**：公开可检索范围内，未见「类脑脉冲解码 + 脑机接口 + 人体通信」三者结合并在 ¥338 国产芯片上闭环实测的成规模工作。
- **领先所需差距**：真实数据（自采脑电 + 真实 HBC 实测）→ within-subject 精度（80~90%）→ 任务复杂度（打字/连续控制）→ 真类脑硬件（神经形态合作）。

## 五、方法论资产（可复用）

1. **世界主流技术筛选流程**：调研 → 同协议移植 → 实测对比 → 上板（EEG-TCNet ✅ / EA ❌ / 剪枝 ❌——**筛选标准是同协议实测，不是名声**）。
2. **三级逐位一致验证**：导出 round-trip 断言 → numpy C 顺序参考（max|diff|=0）→ PyTorch vs C（预测一致率 100%）——部署可信度的标准流程。
3. **诚实边界标注**：板上实测 / 真实训练 / 仿真严格区分；单 seed ±1.7pp 波动（MPS 随机初始化）；结论依赖相对差距。
