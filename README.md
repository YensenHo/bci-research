# BCI 科研（碳硅协同检测解码系统 / HBC × BCI）

可穿戴脑电采集 → 端侧（国产 RV1106 NPU）实时解码 → 人体通信（EQS-HBC）回传的融合闭环，目标世界顶尖的可穿戴脑电解码系统。

2. **`AGENTS.md`** — 项目改动规则
3. **`暂停点_下一步_*.md`** / **`NEXT_STEPS_下一步任务.md`** — 当前进度快照 + 下一步任务（最新的是 `暂停点_下一步_20261027.md`）
