# P0 单通道主动电极 · 验证实验方案（可执行版）

> 目标：验证「主动电极缓冲电路」这一个环节——**它的噪声底 ≤ 湿电极对照的 2×**，就算过。
> 这是整个"采集-去噪一体化前端模组"里唯一没有现成电路的环节，一个数字定成败。
> 预算：¥400–1000（采购清单见 `07_买家访谈清单.md` 同目录的采购表，或直接问我重发）。

---

## 一、先想清楚：P0 到底在验证什么

普通 ADS1299 采集板，电极直接接芯片。问题是干/半干电极的**源阻抗高**（几十 kΩ～几百 kΩ），直接接会把信号吃掉、把噪声放大。

主动电极的核心 = 在每个电极头后面塞一个**高输入阻抗的缓冲运放**，让信号在"离头皮最近的地方"就被低阻抗放大，再走线到 ADS1299。P0 要验证的就是：**这个缓冲，到底能不能让干/半干电极的噪声底逼近湿电极。**

所以 P0 只测一件事：噪声底。别的（阻抗监测、多通道、HBC）一律不做，避免变量混在一起分不清是谁的功劳。

---

## 二、需要准备的东西

1. ADS1299 8ch 模块（淘宝/立创，¥150–300）
2. 低噪声运放（OPA376 首选 / TL072 备用）× 2–3 片
3. Ag/AgCl 湿电极片 × 若干 + 导电膏（金标准对照）
4. 干电极或半干电极头（被测对象，可以用现成的干电极片）
5. 主控板（Arduino Nano / STM32 / 你已有的 RV1106）
6. 面包板 + 跳线 + 阻容（搭缓冲电路）
7. 数字万用表（测电极阻抗）

---

## 三、三个测量条件（必须都测，缺一不可）

| 条件 | 接法 | 作用 |
|---|---|---|
| **A. 输入短接** | ADS1299 通道输入直接短接到地 | 测**系统本底噪声**（芯片+板子自身的噪声，是最低极限） |
| **B. 湿电极对照** | Ag/AgCl 湿电极 + 导电膏，贴额头，经缓冲接到 ADS1299 | **金标准基准**，要逼近的对象 |
| **C. 主动电极（干/半干）** | 干/半干电极头 → 缓冲运放 → ADS1299 | **被测对象** |

判定标准：**C 的噪声底 ≤ B 的噪声底 × 2**，就过。A 是参考下限（C 不可能好过 A，如果 C 接近 A 说明缓冲做得很好）。

---

## 四、缓冲电路怎么搭（先跑通，再调优）

```
电极头 ──► [100kΩ 保护电阻] ──► 运放同相端(+)
                                    │
                                  运放（电压跟随，增益=1，输出接反相端）
                                    │
                                    ▼
                                ADS1299 通道输入
```

- 运放接成**电压跟随器**（增益 1），关键是输入阻抗高（OPA376 是 CMOS 输入，TL072 是 JFET 输入，都行）。
- 运放要**靠近电极头**放（这就是"主动电极"的物理含义），输出用低阻抗走线到 ADS1299。
- 电源：运放用 ±2.5V 或单电源 + 偏置，先跑通再纠结。
- **先买 TL072 跑通电路，噪声底不达标再换 OPA376/OPA140**，别一上来买最贵的。

## 五、测量流程（每步照做）

1. **接通 ADS1299，先读 ID 寄存器**（应为 0x3E），确认 SPI 通信正常。
2. **条件 A（短接）**：所有输入短接到地，ADS1299 采 **2 分钟**，存数据，算 RMS 噪声底（µV）。
3. **条件 B（湿电极）**：贴 Ag/AgCl + 导电膏到额头，采 **2–3 分钟**静息脑电（睁眼静坐即可），算 RMS。
4. **条件 C（主动电极 + 干/半干）**：同样的位置，换干/半干电极 → 缓冲 → 采 **2–3 分钟**，算 RMS。
5. **记录**：每个条件的 RMS（µV）+ 一张功率谱（看 1–50Hz 有没有异常隆起，尤其 50Hz 工频）。

判定：`RMS_C / RMS_B ≤ 2.0` → **P0 通过**，进 P1；否则回到第 4 步换运放 / 换电极头，或退回"被动直连"方案。

## 七、诚实提醒（三条）

1. **50Hz 工频**会严重污染噪声底测量，如果 RMS 被工频主导，先看频谱、再考虑用电池供电 / 远离交流设备 / 软件陷波，但别用陷波掩盖真实噪声。
2. **干电极的源阻抗**是变量，先测一次电极-皮肤阻抗（万用表），记录下来，阻抗异常高（>几百 kΩ）说明接触不良，先解决接触再测噪声。
3. P0 的目的**不是冲指标，是拿一个真实数字**判断这条路线走不走得通。噪声底达标了就进 P1，不达标就诚实回退，别硬撑。
