# Hermes 接手说明

请先阅读本仓库根目录 README.md、HARNESS.md、AGENTS.md，再读本目录 README 和引用文件。遵守主线：BCI 数据 AI 模型与可穿戴部署；情绪只是研究任务之一。未证明临床诊断或商业情绪检测性能；不要据此修改创业仓库、刺激系统或接触人体硬件。

当前的客观结论是消极/不确定：FACED 的有限开发实验中，两个 EEG 对照没有稳定超过训练均值；训练侧人和影片双重留出的结果也没有。DENS 原始文件存在严重长度不匹配的疑点及许可冲突，不作为完整第二数据集。个人校准、失效监测、EEG 无标签何时适配、跨被试和跨刺激以及少通道均有现有工作，不能把组合词视为创新。保留人群 024–031 的 EEG 未用于训练或模型评估；虽曾检查其评分表完整性，不得称完全未读取元数据。

可执行的下一步：
1. **独立审查代码与数据语义**：核对 BDF 缩放、分片、预处理、短基线、视频来源及跨被试/电影拆分，列出具体可重现的 bug 或泄漏，并分别给出反例和影响，先不使用保留人群进行模型选择。
2. 对比 PRED、SPDIM、ResMF 和 2026 FACED 刺激混杂工作；记录类别标签、自评、适配阶段、目标数据是否含标签、素材/被试划分、额外模态及计算预算。仅在代码/数据确实可用、许可允许、协议可比时提出复现，不伪称完成。
3. 寻找权限与来源明确、真实评分和 EEG 事件可核验的第二数据集。EmoEEG-MC 视频/想象和睁闭眼混杂，派生数组与评分顺序尚未独立打通；数据不能靠猜。EMAP 仅学术研究，不可用于改进商业系统；DENS 的数据及许可矛盾未消除。
4. 将可以复核的证据、失败、版本、命令与误差边界写入仓库文档；不提交任何原始 EEG、逐人自评分、包含样本评分的缓存、源版权材料或凭证。部署、医疗功效和硬件安全不得根据模拟或软件检查宣称。
