# 选题生死评估：个人校准情绪脑电

日期：2026-11-18。目的：依据 FACED 与 ON006866 现有探索结果，判断原研究问题是否继续作为第一篇论文主线。本文是研究决策记录，不是正式系统综述或预注册。

## 决策摘要

**暂停把“短时无标签个体校准能否带来超出内容/人群先验的个人自评预测增量，并识别校准不足”作为当前第一篇论文的主问题。** 现有结果没有给出正向增量证据；ON006866 也不具备检验无标签静息校准和跨具体图片泛化的关键数据条件。继续在同一数据上堆模型、校准模块或指标，不能修复任务标签与设计上的缺口。

这不是证明“EEG 不能预测情绪”，也不是永远终止情绪方向。准确判断是：**当前两条探索线未支持原主张，现有公开数据不足以做该主张的决定性实验。** 情绪方向若继续，应转为新采集、预先固定素材与静息方案的前瞻研究；不把当前结果包装成论文有效性证据。

## 一、两条阴性证据的含义

### FACED

Gerster 核心分析的缩小版独立重实现支持：刺激标签的解码超过多数类基线，而主观标签没有超过对应基线；单视频设置的解码率上升。分析使用 16 人、每视频 10 秒、LDS、LOSO，且 LDS 与标准化使用目标被试整段数据，属于离线 transductive 分析，不是在线因果结果或逐位复现。它支持“刺激身份可被 EEG 捕捉，不能把刺激类别准确率等同于主观情绪解码”的警示；不能推广成所有情绪 EEG 均不可解码。

FACED 连续唤醒度探索中，EEG 对照未稳定超过常数/内容先验。拆分样本小，不能排除其他任务、标签或采集方案下存在信号。现阶段它削弱原主张的实证基础，并暴露素材混杂、标签噪声与跨被试泛化风险。

### ON006866

当前跨被试小样本试验有 6 名来源被试、2 名目标被试；每位目标人的前 10 条**有标签自评**用于偏移校准，后 20 条测试。校准后 EEG Ridge 的宏平均 MAE 为 1.6563，校准后的来源均值为 1.6801，差 0.0238；两名目标被试不足以估计稳定性或人群效应。该设置不是无标签静息校准。结果只说明这次微型开发试验未显示清晰、可靠的 EEG 增量，不能据此断言 EEG 无效。

因此，原研究问题目前没有可直接辩护的正向方法贡献。保留的可辩护贡献仅是透明报告两项探索性阴性结果、拆穿把刺激解码误读成情绪解码的风险，以及据此提出更严格的前瞻验证设计；这本身尚不足以支撑目标期刊论文。

## 二、ON006866 三项前提核查

核查对象：固定版本 NEMAR ON006866 v1.0.0，元数据 commit `7350e08e5e5e4cb7d2c96b3933a298b3ef67daa3`。核查了仓库 README、任务事件说明、目标被试 008/009 的 events/channels/eeg JSON，以及已有代码对八名被试 .set 头、事件和所用通道的交叉检查。未下载或发布原始 EEG、逐人评分或图像版权材料。

| 前提 | 核查证据 | 结论 |
|---|---|---|
| 图片身份有充分记录，可留图片 | 固定版本的 `events.tsv` 列为 onset、duration、sample、value；事件字典中的 18–23 是六种“内容×调节条件”，没有具体图片 ID。README 说明使用静态图片，但当前公开事件记录不能把一次呈现唯一映射到图片。 | **不满足。** 可区分六类任务条件，不能据此做按具体图片留出或证明跨新图片泛化。 |
| 有可用任务前静息段 | events 中采集开始标记约在 0.025 s，首个指令约在 2.046 s，首个刺激约在 3.085 s；没有独立静息段标记。采集开始前/后短空档没有眼状态或静息协议证据。 | **不满足。** 不能把开头约两秒称为静息校准，更不能验证静息段无标签适配。 |
| 参考、眼动/肌电、通道缺失与质量已核查 | 目标文件的 EEG JSON 标注参考为 CZ 与 CPZ 之间；数据集 README 的预处理摘要写平均乳突 M1/M2 重参考，二者对应文件阶段需进一步澄清。README 和通道表列有 HEO/VEO（眼电）、EKG、GSR 与 Trigger；没有专用面部 EMG 通道。已有分析显式未重参考、未系统筛查 EOG/肌电伪迹；八人通道名称与通道表一致，所用十个通道存在，但没有基于信号质量的逐通道剔除/插值审计。 | **部分具备传感器/通道元数据，质量前提不满足。** EOG 可用于后续控制或伪迹分析，但不能替代面部 EMG；头信息中的参考口径和原始/处理后关系未解决。 |

**结论：ON006866 不适合支撑原问题的决定性预注册增量实验。** 即使扩大人数，缺少具体图片身份和任务前静息标记也不会因样本增多而消失。可另行设计不依赖静息或图片身份的问题，但那将是不同研究问题，且当前小样本结果不能当作先验确认性证据。

## 三、转向建议：回到科研主轴，单线验证可穿戴鲁棒解码

建议把第一篇工作的候选主线收缩为：**面向可穿戴 EEG 的信号质量感知轻量解码：在通道接触变化、伪迹和计算预算受限时，模型何时仍能解码、何时应拒绝输出。** 这与导师指示的 AI 模型设计＋可穿戴部署相符，也能为 Mood-BCI 提供采集质量监控和端侧推理方法；它是待验证的研究假设，不是已确认创新点。暂不把“情绪自评预测”作为必须成功的目标，也不把医疗诊断或预警纳入论文主张。

建议的可测量任务和门槛：

1. **先选标签定义明确的公开 EEG BCI 任务**，采用按被试/采集日隔离的评估；预先固定主指标、受试者数量、训练/验证/测试拆分和统计单位（被试，而非试次数）。候选任务与数据集须先核查许可、通道和设备采样条件，再冻结，不在看过测试结果后换任务。
2. **问题聚焦一个工程矛盾：鲁棒性与端侧成本。** 对照标准轻量模型与质量感知/通道自适应模型，加入仅在训练侧拟合的通道掉线和噪声扰动；另报告真实数据的未扰动结果，避免只靠合成破坏得到结论。评估解码性能、失效检测/拒绝输出、延迟、内存和目标硬件实测能耗。
3. **把宋勇团队的类脑/时空通道建模当作方法动机，而非创新标签。** 若测试 SNN 或时间—通道注意力，应和相近参数量/计算预算的常规模型在独立测试者上对照；只有预测或部署指标有稳定增益，才保留该方法。
4. **与 Mood-BCI 的互哺方式**：把现有设备用作未来真实信号质量与佩戴条件的外部检查；先建立电极/通道质量的可追溯测量和同步/安全条件，再验证模型。现有 Mood-BCI 原型的多板同步与信号质量问题不能直接充当已标注的噪声数据或独立硬件部署证据。

这是选题方向，不是已完成的创新性检索结论。正式投入前仍需更新竞争方法检索、确认数据许可和实验资源，并在固定协议下完成公开数据基线。若不能得到跨被试的可靠增量或目标硬件实测优势，应继续收缩论文主张，而不是叠加模块。
