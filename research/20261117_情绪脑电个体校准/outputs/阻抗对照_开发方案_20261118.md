# 块级阻抗对照：开发方案（运行前）

数据 Figshare 13560281，固定选择 001–010，仅作开发试验：001–006 来源训练，007–008 验证，009–010 独立目标测试，永不以测试结果调设置。阻抗数组索引 0 的均值 261.67、索引 1 为 19.63，与原论文干/湿均值吻合，推断阻抗索引 0 干、1 湿；EEG 依数据集 README 索引 0 干、1 湿。阻抗分布只能支持阻抗维映射，不能独立证明 EEG 映射。两个域均值比约 13.33；中位数比约 9.48，因此不以中位数必须超过 10 倍为条件。运行时检查分布与均值比大于 10；测量单位及数据论文条件继续核对。

候选方法固定：使用两类电极、全部 10 块和 12 类，采样 250 Hz，取刺激后 2 秒（去除前 0.5 秒及后 0.34 秒），每通道各目标频率及二次谐波附近的复数傅里叶幅值。来源人训练 StandardScaler+RidgeClassifier，对逐通道质量值超过来源训练集 80 分位数的通道特征置零，分类器始终使用原始特征训练：三个条件无屏蔽、块前阻抗屏蔽、试次波形标准差屏蔽。标准差只用该试次，不使用标签；这是时序不匹配的探索对照，不能作为同成本结论；掩码机制导致的零值与标准化尺度须按相同管线执行。报告每位被试宏平均准确率以及遮蔽比例，不发布逐试次数据。目标以被试为单位，样本仅 2 人，不做显著性和创新结论。该离线特征为探索流程，非实时系统或正式预注册。完成前禁止根据目标结果修改方案。
