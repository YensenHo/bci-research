# 阻抗与 EEG 数据核查及实验接续（2026-11-18）

## Nature 临床数据

[Chamanzar 等 2023](https://doi.org/10.1038/s43856-023-00344-3) 的 [开放 PDF](https://medtion-image.medtion.com/uploads/1/file/public/202310/20231030163328_go2wn5kteb.pdf) 方法和数据声明：12 位重型脑损伤患者，19 导 scalp EEG（256 Hz），ECoG 专家标注 700 次扩散性去极化事件；CNS Advanced ICU EEG Amplifier 每电极连续记录 1 Hz 阻抗。论文未明确其激励电流或测量频率。每电极全程中位阻抗两倍以上的段落置零并从后续功率估计排除；该全程统计使用未来信息。原始匿名 EEG 仅可能经申请、合同及数据共享协议取得，补充表不是原始记录。不可直接跑原论文数据，未经授权未联系作者。

## 公开替代：可穿戴 SSVEP，块级阻抗

[Zhu 等 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC7916479/)、[Figshare 13560281](https://doi.org/10.6084/m9.figshare.13560281)：102 人、8 通道、12 个 SSVEP 刺激目标，干/湿电极各 10 块。每块开始前记录电极阻抗，与相应块匹配，**不是连续同步记录**，不测块内接触动态变化。Figshare API 标注数据 CC BY 4.0。原论文已经分析被试平均阻抗与准确率的相关性；我们的问题须比较阻抗与波形质量控制，而非声称首次分析关系。

2026-11-18 已下载 Impedance.mat（117814 字节）及 S001.mat（9824536 字节）至仓库外 `outputs/ssvep_private/`。SciPy 实测字段分别为 `Impedance (8,10,2,102)` 和 `data (8,710,2,10,12)`；目标标签来自最后一维。注意 [数据说明](https://bci.med.tsinghua.edu.cn/upload/zhufangkun/Readme.pdf) 中 EEG 电极维是 1=干、2=湿，而阻抗维写 1=湿、2=干；论文对阻抗维的形状又有不同写法。**必须通过全体数值分布和原文核对后再配对，不可假设两个维度顺序一致。** 文件哈希分别为 MD5 `dc1a6b215bb37f5cc7220dd012da224b`、`ca8c67298b8ba347dc633f47591d96b2`；仅记录下载字节，不代表已与官方校验。未发布原始数据。

## 下一步工作记忆

1. 固定探索性方案后下载其余预定受试者，校验 Figshare API 文件大小/MD5；数据和缓存一律保留在仓库外，不上传个人信息。
2. 查原文和实际文件确认干湿维度、阻抗单位、刺激频率及正确对齐；检查缺失/异常，不查看测试标签调阈值。若无法确认映射，中止对照并报告。
3. 按受试者隔离训练/验证/测试；统一清晰掩码粒度和拒绝成本，训练侧拟合阈值，比较无掩码、块前阻抗、同等信息时序下的波形质量三种方法，报告每人准确率、覆盖率和配对不确定性。不可把波形指标在试次期内计算但阻抗仅块前测得的差异忽略；另报相同块级时间预算对照。
4. P1 尚未运行。此数据只能评估块级测量，不能证明连续质量检测、MI 或自有硬件有效。正式预注册应在开发和阈值冻结后，使用独立未触碰的人群；材料可用不意味着实验效果成立。
