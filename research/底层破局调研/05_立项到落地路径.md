# 采集-去噪一体化前端模组 · 从立项到落地路径

> 本文档回答一个问题：如果要做「主动电极 + 片上阻抗感知 + HBC 组网 + 端侧实时去噪」一体化前端模组，从立项到落地怎么走、每一步验证什么、花多少钱、卡在哪儿。
> 数据来源：`01_采集技术.md`、`02_刺激技术.md`、`03_全景与市场.md`、`采集去噪一体化前端模组技术实现路径报告.md`、`脑电采集前端模组_市场格局与价格锚_调研报告.md`。凡估算/待核实处均已标注，不编造。

---

## 0. 一句话定位

做一个「**开箱即得干净脑电信号**」的前端模组，卖给脑电设备商和 BCI 创业公司。卖点不是"我们做了采集"，而是"**你省掉了 AFE + 主动电极 + 去噪的研发时间，买到一条可复现的干净信号通路**"。

差异化不是任何单项技术，而是**组合 + 形态**：把「主动电极 + 阻抗感知 + HBC 组网 + 端侧去噪」整合成一个向下游供货的 OEM 模组。公开可检索范围内，这个组合形态目前没人做。

## 1. 立项：卖给谁、为什么买、什么价

### 1.1 目标买家（第一波）

| 买家 | 付费点 | 切入难度 | 优先级 |
|---|---|---|---|
| **脑电设备厂商（OEM）** | 把"前端"当零部件买，省 AFE+去噪研发 = 真金白银 | 低（就是 B2B 供货） | **第一波** |
| **BCI 创业公司** | 快速搭原型、要干净信号喂解码 | 低（量小但决策快、定制需求高） | **第二，配合 OEM** |
| 中小科研课题组 | 有经费、要可复现，但预算敏感 | 中（采购慢、品牌偏好） | 中长期 |
| 医疗设备商 | 强付费意愿，但需 CFDA/FDA 认证 1-3 年 | 高 | 后期，初期不做 |

**关键判断：第一波锁定 OEM + BCI 创业公司。** 他们不挑品牌、决策快，为"省研发时间 + 信号质量保证"付费。

### 1.2 价格锚（已确认数字 + 建议切入价）

| 对标 | 价格 | 状态 |
|---|---|---|
| OpenBCI Cyton 8ch（裸采集板，无主动电极/去噪/组网） | $1249 | 已确认 |
| OpenBCI 16ch / Ganglion 4ch | $2499 / $624.99 | 已确认 |
| Emotiv EPOC X 14ch / Muse 2 | $1199 / $249.99 | 已确认 |
| 科研级整机（BrainProducts/BioSemi/g.tec） | 数万-数十万美元，询价制 | 待核实（仅量级） |

**建议切入价**：8ch **$1500–2500**、16ch **$3000–4000**、32ch **$7000–9000**；**OEM 批量价 8ch 可到 $800–1500**（打 OEM 市场的核心武器）。

定价逻辑一句话：**按"信号质量/功能"对标科研级打 1/5–1/10 折，按"形态"对标 OpenBCI 溢价 20–100% 换一体化。** 不要定成芯片价（那是卖裸 BOM），也不要试图对标 BrainProducts（品牌+认证短期进不去）。

### 1.3 空白判断（这是整个方向成立的前提）

- 单点不空白：主动电极（BioSemi/actiCAP）、片上 AFE（TI/ADI）、on-chip 去噪（Feng 2020 已有 ICA+小波片上实现）、无线组网（各整机）都有人做。
- **组合形态空白**：无人把「主动电极 + 阻抗感知 + HBC 组网 + 端侧去噪」整合成可采购的 OEM 模组。
- 真正差异 = **HBC 组网（宋勇实验室独有栈）+ 端侧轻量去噪 + 模组化出货**。

## 2. 技术架构（已确认可行性 + 推测整合）

```
[主动电极×8] ──缓冲+阻抗监测──► [ADS1299 8ch AFE] ──SPI──► [RV1106]
      │              (菊花链可扩 16/32ch)                    │
      └────────── HBC/EQS-HBC 组网（替换线缆）◄───────────────┘
                                                              │
                             去噪：LIF-EEG-TCNet（CPU，已验证 ~50ms）
                             或 nASR/轻量 CNN（芯片化后走 NPU，待工具链修复）
```

- **AFE**：TI ADS1299（8ch，噪声 1µVpp、16kSPS、CMRR -110dB、1ku **$45.91**，已确认）。ADS1298 可降本（$25.58），但噪声 4µVpp 略差。
- **主动电极**：片上缓冲+阻抗监测，标杆功耗 160µW/8ch（20µW/ch）。
- **HBC**：EQS-HBC 节点 415nW、OpenIBC 4096bps/7.4µW；RV1106 用 PWM 1MHz 载波已板载实测。
- **去噪**：RV1106 的 NPU 对 EEGNet 类小模型 INT8 量化失真（argmax 掉到 42-58%，是工具链 bug），当前去噪/解码走 CPU（18.5-50ms）或换 SNN。**别把 NPU 当"还差一个旋钮"。**

## 4. 分阶段里程碑（每步有验收数字 + Kill 条件）

| 阶段 | 目标 | 验收数字 | Kill 条件 | 时间盒 |
|---|---|---|---|---|
| **第 0 步 · 立项验证** | 确认真有人付钱 | 3-5 家 OEM/BCI 公司明确表示愿意试用/预购 | 聊了 10 家没人要 → 不立项 | 2-4 周 |
| **P0 · 单通道** | 验证主动电极最不确定的一环 | 主动电极噪声底 vs 湿电极对照 ≤ 2× | 噪声底 > 湿电极 2× → 退回被动方案 | 1-2 月 |
| **P1 · 8 通道** | 复用已验证 8ch 解码栈 | 8ch 复现 BCIC 2a 精度、测串扰 | 串扰/共模不过关 → 优化参考电极 | 1-2 月 |
| **P2 · HBC 组网** | 电极→集线器用 HBC 替换线缆 | 经 HBC vs 直连解码精度差 ≈0（McNemar 不显著） | 多节点同步 3 月不收敛 → 先退有源线缆 | 2-3 月 |
| **P3 · 小批量+卖** | 卖出第一批、收真实回款 | 3-5 家付钱，单台毛利为正 | 无人复购 → 重新定位买家 | 视资源 |

**P0 是生死验证**：主动电极的"输入缓冲 + 阻抗监测"是整个模组与"普通 ADS1299 采集板"的唯一差异，也是唯一没有现成已验证电路的部分。P0 一个数字定成败。

## 5. 三个诚实的边界（别自己骗自己）

1. **这个模组本质还是基建，不是终极护城河。** 符合 HARNESS P2——采集去噪是"卖水人"生意，做得再好不容易被别人抄走多少，因为 ADS1299 谁都能买、主动电极电路有公开文献。**模组做"成本/集成度门槛"，真正的护城河在"这个模组采回来的真实多模态数据 + 疾病机制 + 干预方案"。** 模组是入场券和现金流，不是终点。

2. **RV1106 NPU 有硬伤**：INT8 对 EEGNet 类小模型失真（argmax 42-58%），当前只能 CPU 或 SNN。别在 BP 里写"NPU 实时去噪"。

3. **国产 AFE 未经验证**：公开规格/价格缺失，宣传"软硬件兼容 ADS1299"需样片实测背书。

## 6. 需要你拍板的三个决策点

1. **第一个买家到底是谁？** 我倾向"OEM 脑电设备商"，但你更熟国内产业链，是否先聊几家确认？这一步决定 M1 能不能过。
2. **初期碰不碰医疗器械红线？** 我建议初期按"科研/开发板性质"出货（不诊断、不治疗），完全绕开注册证；医疗客户放后期。你认不认？
3. **护城河叙事怎么定？** 模组做现金流、数据做护城河——这个定位你同意的话，HARNESS 的 P2 我要按这个口径精确化。
