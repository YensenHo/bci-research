# 脑电采集前端 / 放大器 / 模组：市场格局与价格锚调研报告

> 调研目标：摸清"脑电采集前端/放大器/模组"的市场格局与价格锚，判断「采集-去噪一体化模组」卖给谁、什么价位、以及"一体化"是否真空白。
> 委托人背景：非侵入式 BCI，端侧芯片部署（¥338 国产芯片/RV1106）、类脑脉冲网络(LIF)、人体通信 HBC/EQS-HBC（宋勇实验室 2012 年起，早国际 7–10 年）。战略方向 = 采集-去噪一体化前端模组（主动电极 + 片上阻抗感知 + HBC 组网 + 端侧实时去噪）。
> 数据源：OpenBCI 官网 products.json、TI 官网、Emotiv/Muse 官网、OpenAlex 学术 API、以及此前已核实的电极采集前沿文献库（`eeg-electrode-acquisition-frontier.md`）。核实日期：2026-09-18。
> 标注约定：**【已确认】** = 直接抓取到官方公开数据；**【待核实】** = 官网询价制/无法匿名抓到确切数字，只给量级与来源提示，绝不编价。

---

## 0. 一句话结论（先给答案）

1. **卖给谁最现实**：脑电设备厂商（OEM/零部件采购）+ BCI 创业公司（快速原型）+ 预算敏感的中小科研课题组。最容易切入的是 **OEM 与 BCI 创业公司**——他们把"干净信号前端"当零部件买，付费买的是"省掉的 AFE+去噪研发时间 + 信号质量保证"，而不是品牌。
2. **合理切入价位**：8 通道 **$1500–2500**、16 通道 **$3000–4000**、32 通道 **$7000–9000**（OEM 批量价可下探到 8ch 约 $800–1500）。定位 = 比 OpenBCI Cyton（$1249，无主动电极/无去噪/无组网）略高，远低于科研级整机（数万美元）。
3. **"采集-去噪一体化"是否真空白**：**单点技术都不空白**（主动电极、片上 AFE、去噪算法、on-chip 去噪、无线组网都有成熟玩家），但 **"主动电极 + 阻抗感知 + HBC 组网 + 端侧实时去噪"整合成一个【可采购的 OEM 模组】卖给下游**这个产品形态，在公开可检索范围内是空白。差异化不在"能做"，而在"整合 + 端侧轻量化 + 模组化出货"。

## 3. 「采集-去噪一体化」是否真空白？（差异化判断核心）

### 3.1 谁已经在做（按"做到什么程度"分层）

**A. 芯片层（只有 AFE，不集成）**
- TI ADS1299/ADS1298、ADI AD777x/AD594x：裸 AFE，**无主动电极、无去噪、无组网**。谁都能买，不构成护城河。【已确认】

**B. 学术层（单点已有先例）**
- **主动电极 ASIC**：`A 160μW 8-Channel Active Electrode System for EEG Monitoring`（IEEE TBCAS 2011, DOI 10.1109/tbcas.2011.2170985）——8 通道主动电极系统芯片已做。【已确认存在】
- **主动电极综述**：Xu 2017 IEEE Rev BME（DOI 10.1109/rbme.2017.2656388）；Habibzadeh 2020（DOI 10.1109/jsen.2020.3012394）。【已确认存在】
- **on-chip 去噪**：`Fast automated on-chip artefact removal of EEG for seizure detection based on ICA-R algorithm and wavelet denoising`（Feng, Li, Zhang, IET Circuits Devices & Systems 2020, DOI 10.1049/iet-cds.2019.0491）——**已有人把 ICA + 小波去噪做到片上**（面向癫痫检测的可穿戴/嵌入式场景）。【已确认存在，这是"端侧去噪"最直接的对标物】
- imec 曾做 8 通道无线干电极 EEG 头戴参考设计（约 2015–2019），属"研究所级整合样机"，未形成可采购的 OEM 模组商品。【待核实具体型号，但方向明确】

**C. 商业整机层（整合了，但不卖模组、不去噪在端侧）**
- BioSemi ActiveTwo / BrainProducts actiCAP：**主动电极 + 片上阻抗测量 + 放大器**已整合，但是**封闭整机 + 上位机去噪**，不出 OEM 模组。【已确认形态】
- mBrainTrain Smarting（24ch 无线）、TMSi SAGA（32/64/128ch）、g.tec g.Nautilus（8–64ch 无线）：无线 + 主动电极整机，去噪仍在软件侧，**不卖前端模组给第三方**。【形态已确认，价格待核实】
- OpenBCI Cyton + ThinkPulse 主动电极：**开源板 + 可加主动电极**，是"离模组最近"的东西，但去噪（OpenBCI GUI 的滤波/ICA）跑在上位机、无片上阻抗感知、无 HBC 组网。【已确认】

### 3.2 结论：空白在"组合 + 形态"，不在"单点"

| 能力 | 是否已有人做 | 谁 |
|---|---|---|
| 主动电极 | 已成熟 | BioSemi、BrainProducts actiCAP、ThinkPulse、学术 ASIC |
| 片上阻抗感知 | 已有 | actiCAP 电极内阻抗测量、ADI AD594x |
| 端侧/片上实时去噪 | 学术已有先例 | Feng 2020（ICA-R+wavelet 片上） |
| 无线组网 | 已有 | 蓝牙/WiFi 各整机 |
| HBC（人体通信）组网 | 实验室阶段 | **宋勇实验室 EQS-HBC（2012 起，早国际 7–10 年）——这是独有栈** |
| **"主动电极+阻抗感知+去噪+HBC组网"整合成一个【可采购的 OEM 模组】卖给下游** | **公开可检索范围内空白** | **未见** |

> **诚实表述（遵守诚实护栏）**：不能宣称"全球首创/唯一"。准确的差异化表述是——
> 「在**公开可检索范围内**，尚无人把『主动电极 + 片上阻抗感知 + 人体通信组网 + 端侧实时去噪』整合成一个**向下游设备商供货的前端模组**；现有玩家要么只做芯片（TI/ADI），要么只做封闭整机（BrainProducts/BioSemi/g.tec），去噪都留在上位机软件。on-chip 去噪在学术层已有先例（Feng 2020），故真正的壁垒不在"能去噪"，而在 **HBC 组网 + 端侧轻量去噪 + 模组化出货的组合**，以及委托人已有的类脑脉冲 + 端侧芯片部署栈。」

## 4. 价格锚分析：一体化模组切入价

### 4.1 成本侧（BOM 量级，估算）

- 8ch AFE 芯片：$25–52（ADS1298→ADS1299）
- 主动电极（缓冲+屏蔽）：电极端每通道 $5–20 量级（ThinkPulse 8 电极套件 $499.99 可参考，但含品牌溢价）
- 端侧 MCU/SoC：RV1106 约 ¥40–60（~$6–9）、或 ¥338 级国产芯片
- 去噪固件：一次性研发成本，边际成本≈0
- **8ch 模组 BOM 估算 $60–150**；16ch $120–250（不含外壳/认证/良率）

### 4.2 定价侧（对标）

| 对标 | 价格 | 相对关系 |
|---|---|---|
| OpenBCI Cyton 8ch（裸采集板，无主动电极/去噪/HBC） | $1249 | 下限参照 |
| OpenBCI 16ch | $2499 | |
| Emotiv EPOC X 14ch（半干+黑盒去噪） | $1199 | 消费级上限 |
| 科研级 32–64ch 整机 | 数万–数十万美元 | 上限 |

### 4.3 建议切入价（判断，非事实）

- **8 通道：$1500–2500**（略高于 Cyton，因叠加主动电极 + 阻抗感知 + 端侧去噪 + HBC 组网；仍远低于科研整机）
- **16 通道：$3000–4000**
- **32 通道：$7000–9000**
- **OEM 批量价（给设备商的零部件价）：8ch 可到 $800–1500**——这是打 OEM 市场的核心武器：设备商买"干净信号前端"比自研 AFE+去噪便宜得多、快得多。

> 定价逻辑：**按"信号质量/功能"对标科研级（打 1/5–1/10 折），按"形态"对标 OpenBCI（溢价 20–100% 换一体化）**。不要定成芯片价（那不是模组生意，是卖裸 BOM），也不要试图对标 BrainProducts（品牌与认证壁垒短期进不去）。

## 5. 目标买家画像（谁最容易切入、付费意愿最强）

| 买家 | 需求 | 付费意愿 | 切入难度 | 判断 |
|---|---|---|---|---|
| **(a) 科研机构/高校实验室** | 干净信号、高通道、可复现 | 强（有经费） | 中高（采购流程慢、品牌偏好 BrainProducts/g.tec、预算敏感的中小课题组才买 OpenBCI） | 中长期市场，不优先 |
| **(b) 脑电设备厂商（OEM）** | 把"前端"当零部件，不自研 AFE+去噪 | **最强（省研发 = 真金白银）** | **低**（就是 B2B 供货） | **最现实、最先切入** |
| **(c) BCI 创业公司** | 快速搭原型、要干净信号喂解码 | 中强（量小但定制需求高、决策快） | 低 | **第二优先，配合 OEM** |
| **(d) 医疗设备商** | 需过 CFDA/FDA，要求临床证据 | 强但周期长 | 高（认证 1–3 年） | 后期，初期不做 |

**结论：以 (b) OEM + (c) BCI 创业公司为第一波客户**。他们的共性付费点 = "买到的不是板子，是**省掉的 AFE + 主动电极 + 去噪研发时间，和一条可复现的干净信号通路**"。这正好把委托人"采集是基建"的短板，转成"我帮你把基建做扎实"的卖点。

---

## 6. 结论（给委托人的直接回答）

1. **卖给谁最现实**：脑电设备厂商（OEM 零部件）+ BCI 创业公司（快速原型），辅以预算敏感的中小科研课题组。第一波客户锁定 OEM 与 BCI 创业公司——他们为"干净信号前端 + 省研发时间"付钱，不挑品牌、决策快。

2. **合理切入价位**：8ch $1500–2500、16ch $3000–4000、32ch $7000–9000；OEM 批量价 8ch $800–1500。定位锚点 = OpenBCI Cyton（$1249，裸采集板）之上、科研整机（数万美元）之下的巨大空档。

3. **"采集-去噪一体化"是否真空白**：**单点不空白**（主动电极→BioSemi/actiCAP，片上 AFE→TI/ADI，on-chip 去噪→Feng 2020 学术先例，无线组网→各整机）；**组合形态空白**——公开可检索范围内，无人把「主动电极 + 片上阻抗感知 + HBC 组网 + 端侧实时去噪」整合成一个向下游供货的 OEM 模组。真正的差异化 = **HBC 组网（宋勇实验室独有栈）+ 端侧轻量去噪 + 模组化出货**的组合，而非其中任何单项。
