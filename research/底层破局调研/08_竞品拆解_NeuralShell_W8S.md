**核心结论（技术层面）**：
- **采集前端 = TI ADS1299**：与官网宣称的 24bit / CMRR 110dB / 噪声 0.4μVrms 完全吻合，再次印证
  ADS1299 是脑电采集的事实标准（OpenBCI、Emotiv 等商用系统同样用它）。
- **无线方案 = WiFi**（分离式射频模块 + 屏蔽罩），非人体通信（HBC）——主控手写 J78WUS 且有独立
  WiFi 模块，说明主控本身大概率不带 WiFi，是「MCU + 分离 WiFi 模块」架构。
- **主控 J78WUS 待识别**：手写标记非标准型号，需进一步查证（可能是国产 MCU 定制丝印）。
- 板卡为异形黑色 PCB、2 处安装孔，正面放大型芯片，背面放无线模块/电平转换/状态灯/预留焊盘。

> 拆解前第 3 节的推断 1（AFE ≈ ADS1299）已由实物丝印确认。

## 0. 为什么拆它（对照我们的方向）

我们方向 = **采集-去噪一体化前端模组**（主动电极 + 片上阻抗感知 + HBC 组网 + 端侧实时去噪）。
NeuraShell W8S 是**国产无线脑电套件**，公开宣称「主动降噪式电极传感器 + 阻抗监测 + 干电极即穿即用」——几乎是我方「采集-去噪前端」的产品化形态。拆它是**竞品实物对标**：搞清它的 AFE 芯片选型、无线方案、电极/去噪实现，直接校准我们的技术路线和差异化。

## 3. 关键推断（拆解前，供拆解时验证）

1. **AFE 芯片 ≈ TI ADS1299 或同规格 Σ-Δ**：24bit + CMRR 110dB + 噪声 0.4μVrms 三个指标**精确吻合 ADS1299**（24bit / ~110dB CMRR / ~1μVpp 噪声）。**拆解第一要务 = 确认 AFE 芯片丝印**，若就是 ADS1299，说明我方「采集前端同质化」判断成立（芯片公开可买，护城河不在采集）。
2. **主控 = WiFi SoC（大概率 ESP32 或国产 WiFi MCU）**：WiFi 2.4/5GHz 双频 + 可拆卸锂电 + 14h 续航，指向 ESP32 类方案。
3. **无线方案是根本差异**：它用 WiFi（功耗高、需天线、受距离/干扰限制）；我方用 HBC 人体通信（功耗低几个数量级、无需天线）。这是拆解后要重点讲清的差异化。

## 5. 拆解后要回答的三个问题（写入后续调研结论）

1. **采集前端是否同质化**：若它也是 ADS1299，则印证「采集是基建、护城河不在采集」——我方差异化必须落在「HBC 组网 + 端侧去噪 + 数据飞轮」，而非 AFE 本身。
2. **去噪是真技术还是营销话术**：「主动降噪式电极」到底是硬件（屏蔽+主动电极）还是软件（伪迹去除）？拆开看电极帽内有无前端放大。
3. **WiFi vs HBC 的功耗/形态差**：它的 WiFi + 1500mAh 电池撑 14h；我方 HBC 的功耗优势能否在「电池续航 + 体积」上形成可量化卖点。
