# 采集-去噪一体化前端模组 · 技术实现路径拆解报告

> 委托背景：北理工仪器学院博士，非侵入式脑机接口。技术栈 = 端侧芯片部署（¥338 国产 RV1106）+ 类脑脉冲网络（LIF）+ 人体通信（HBC/EQS-HBC，宋勇实验室 2012 起）。
> 战略聚焦：把「采集-去噪一体化前端模组」做透 = 主动电极 + 片上阻抗/伪影感知 + HBC 体域网组网 + 端侧类脑脉冲实时去噪。
>
> **本报告性质**：工程技术实现路径（芯片/架构/成本/里程碑），非对外 BP/卖点材料。
>
> **⚠️ 定位红线（HARNESS P2 提醒）**：采集与去噪是行业基建、同质化严重，**不能作为护城河/核心卖点**。本模组的战略价值是「把采集基建的成本/集成度/信号质量门槛压低，为上层『生命健康整合系统』供好数据」，护城河仍在「疾病机制理解 + 干预方案 + 真实数据」上。本报告只回答「怎么造出来」，不回答「凭什么赢」。
>
> **数据可信度标注**：全文区分【已确认】（官网/数据手册/API 实时核实）、【待核实】（来源不可达或未找到公开规格页）、【推测/估算】（无公开来源，量级推断）。

## 0. 一句话结论

- **AFE**：8 通道用 **TI ADS1299**（1 µVpp、250–16 kSPS、1ku ≈ $46，TI 官网实时核价），是脑电采集事实标准；低成本/高通道用 ADS1298（4 µVpp、32 kSPS、1ku ≈ $26）。国产 ADS1299 级 EEG 专用 AFE 刚起步（「国芯思辰 8 通道兼容 ADS1299」「ADX920Q 系列」），**型号与价格均待核实**。
- **主动电极**：单电极 = 缓冲/仪表放大器 + 阻抗监测（lead-off）+ 数字菊花链，公开标杆 8 通道整系统 160 µW（20 µW/通道）。
- **HBC 组网**：EQS-HBC 是电极→集线器低功耗互联的最优解，公开节点低至 **415 nW**（65nm CMOS），开源接收机 4096 bps/7.4 µW；委托人已打通 1 MHz OOK 载波（RV1106 PWM 直接生成，实测 1 MHz 精确）。
- **端侧去噪**：轻量 LIF-EEG-TCNet（9.5K 参数）已上 RV1106 CPU 板载（50 ms/前向）；**RV1106 NPU 的 INT8 对 EEGNet 类小模型存在工具链失真（argmax 一致率 42–58%），解码/去噪当前走 CPU 或换轨 SNN**。
- **BOM（估算）**：8 通道模组小批量 ≈ **¥600–1200**，量产可压至 **¥300–600**（核心是 ADS1299 一块 ¥330–380 + 主控 + 电极）。
- **里程碑**：原型（单通道验证电路）→ 8 通道同步 → HBC 组网 → 量产化，分 4 阶段，每阶段 1 个「可证伪验证 + 1 个主要难点」。

## 2. 主动电极电路设计

### 2.1 技术要点【已确认，文献级】

- **主动电极定义**（Xu 2017，IEEE Rev. Biomed. Eng.，10.1109/rbme.2017.2656388）：在电极内**本地放大并缓冲 μV 级 EEG 信号**后再驱动线缆/互联，低输出阻抗缓解线缆运动伪影，从而能用**高阻抗干/半干电极**。这是「干电极 + 前端电子学」能成立的前提。
- **阻抗与噪声**（Habibzadeh 2020，IEEE Sensors J.，10.1109/jsen.2020.3012394）：主动/被动干电极的阻抗与噪声对比综述，量化了「高阻抗电极必须靠前端缓冲」这一结论。
- **功耗标杆**：《A 160 µW 8-Channel Active Electrode System for EEG Monitoring》（2011，IEEE TBioCAS，10.1109/tbcas.2011.2170985）= **160 µW/8 通道 = 20 µW/通道** 的完整主动电极系统。

### 2.2 单电极电路架构【推测/工程判断，基于文献要点】

每个主动电极的片上/电极内电路分四块：

1. **输入缓冲/仪表放大器**：高输入阻抗（>1 GΩ）+ 低噪声（<1 µVpp 输入参考）+ 高 CMRR（>100 dB，Xu 2017 强调）。单位增益缓冲即可（后续 AFE 做增益），目标是「电极界面 → 输出」低阻抗驱动，消除线缆/互联伪影。
2. **阻抗监测（lead-off detection / 阻抗感知）**：注入已知电流（如 6 nA @ 31 Hz，ADS1299 内置）或交流小信号，测电极-皮肤接触阻抗，实时上报「接触质量」。这是「片上阻抗/伪影感知」的核心——闭环判断「这个电极当前能不能信」。
3. **偏置/参考（bias/reference）**：共模抑制靠参考电极 + 主动偏置回路（ADS129x 的 BIAS 输出），干电极系统里参考电极选择直接影响质量（IFCN Seeck 2017）。
4. **数字接口**：SPI 菊花链（ADS129x 官方级联）或串行总线，让每个电极可寻址、可上报阻抗状态。

**与 ADS1299 的接口**：ADS1299 已内置 8 通道 PGA + 24-bit ADC + lead-off 检测 + BIAS，所以「主动电极」可以是**极薄方案**——电极头只做高阻抗缓冲 + 阻抗注入，ADC 仍集中在 AFE；也可做**全分布式方案**——每电极自带低功耗 ADC（如 20 µW/通道的 ASIC），HBC 回传数字。前者成本低、后者抗伪影最彻底。

## 3. HBC 体域网组网

### 3.1 标准与原理【已确认 + 待核实】

- **IEEE 802.15.6（WBAN）**定义三种物理层：窄带（NB）、超宽带（UWB）、**人体通信（HBC）**。HBC PHY 用静电/电容耦合的电场通信（EFC），中心频率 21 MHz，速率从 ~164 kbps 到 ~1.3125 Mbps【具体速率档待核实，未抓标准原文】。
- **EQS-HBC（电准静态人体通信）**：Maity et al. 2018（arXiv 1805.05200）建立 1 MHz 以下人体信道的集总生物物理模型；Sen 组 2019（Sci. Rep. 10.1038/s41598-018-38303-x）证明 EQS-HBC 可实现「隐蔽体域网」（信号约束在体表，不外泄）。
- **两种耦合**：**电容耦合**（电极与人体之间容性耦合，返回路径经人体-大地电容）与**电流耦合/流电耦合**（电极直接接触注入电流）。委托人既有技术栈是 EQS-HBC 电容耦合（1 MHz OOK 载波）。

### 3.2 功耗 / 速率 / 可行性【已确认】

| 方案 | 数据率 | 功耗 | 来源 |
|---|---|---|---|
| **EQS-HBC 节点（65nm CMOS）** | 中低速率（kB/s 级） | **415 nW**（物理+数学安全） | CICC 2020，10.1109/cicc48029.2020.9075930 |
| **OpenIBC 开源接收机** | **4096 bps** | **7.4 µW** | fwolling/OpenIBC（AS3930 前端） |
| **委托人 1 MHz OOK** | ≤5 kbps（符号级） | TX=PWM 无额外 DAC | `rockchip-edge-boards` 板载实测：RV1106 PWM 1 MHz 载波精确生成 |

**可行性结论（已确认）**：
- **载波生成**：RV1106 板载 PWM 实测可精确生成 1 MHz 载波（period_reg 量化精确），无需额外 DDS（旧「PWM 达不到 1 MHz 要 AD9833」结论已推翻）。
- **接收**：RV1106 SARADC（2 通道×10bit @1.8V，~22 kSPS）够做 1 MHz OOK 包络采样（符号率 ≤5 kbps 有 4+ 样本/符号）；PWM 3.3V 输出必须分压 ≤1.8V 才进 ADC。
- **信道损耗**：体表体耦合 1 MHz ≈ 33 dB（皮肤+脂肪+肌肉），穿颅 ≈ 46 dB（颅骨仅 ~8 dB，其余是返回路径损耗）——损耗可控，链路预算成立。
- **组网**：EQS-HBC 天然适合「多电极 → 集线器」星型/体表互联（每电极一个 HBC 节点，分时上报）。节点功耗 415 nW 级意味着**每电极 HBC 通信开销可忽略**（相比 20 µW/通道放大）。

**难点（推测）**：多节点 HBC 的**介质访问（时分/码分）+ 同步**是主要工程难点；电极间体表信道干扰、运动下信道时变需靠协议+纠错兜底。

## 4. 端侧去噪部署

### 4.1 三条去噪路线对比【已确认】

| 路线 | 代表 | 部署可行性 |
|---|---|---|
| **ASR（伪影子空间重建）** | Chang 2019（最优参数 20–30）；Maanen 2022（arXiv 2204.13444，可部署受限硬件）；nASR 神经层（arXiv 2605.14941） | ASR 核心是 PCA/SVD 子空间投影，**算力可预测**，但 SVD 在线计算 + 标定对 MCU 是负担；nASR（可训练神经层版）更适合芯片化 |
| **深度学习去噪** | SPAR-EEG（单通道可穿戴，PMID 42747931）；MoE 按 SNR 分专家去 EMG（PMID 42716081） | 与解码共用一个轻量 CNN，端侧可行；但要「去噪+解码」两套网络，算力翻倍 |
| **类脑脉冲去噪** | 委托人 LIF-EEG-TCNet | **已上 RV1106 板载**：9.5K 参数、50 ms/前向（CPU），SNN 0/1 脉冲天然规避 INT8 量化失真 |

### 4.2 RV1106 算力与落地结论【已确认，板载实测】

- **RV1106G3**：Cortex-A7 @1.2 GHz + RISC-V 协处理器 + **0.5 TOPS NPU**。
- **⚠️ NPU 不可用（对 EEGNet 类小模型）**：RV1106 NPU 的 INT8 量化对深度可分离小模型（EEGNet/TCNet）严重失真，argmax 一致率仅 42–58%；已用 fake-quant 仿真定位为**RKNN 工具链 bug 而非 INT8 精度极限**（PyTorch 侧标准 INT8 PTQ 一致率 98–99%）。**结论：解码/去噪当前走 CPU 推理（18.5–50 ms），NPU 需等工具链修复或换 hybrid/CPU 回退。**
- **CPU 推理余量**：8 通道二分类 18.5 ms、四分类 22 通道 50 ms（2 s 窗口 = 40× 实时余量），去噪+解码串行仍绰绰有余。
- **类脑换轨是「绕开 NPU bug」而非「修 bug」**：LIF 的 0/1 脉冲 + 累加（无连续激活、无 INT8 乘法）天然规避量化失真；这已是被 7 个任务验证的零代价换轨（类脑化精度追平 ANN）。

### 4.3 去噪算力估算【推测/估算】

- 轻量 ASR/nASR 或去噪 CNN（<10K 参数）与解码同量级（<7M MACs），CPU 上 1–50 ms 级，可实时。
- 若「去噪 + 解码」共用一个 LIF 网络（隐式去噪 + 任务解码），算力不翻倍——这是推荐路线：**让 HBC 噪声增强训练（已实现，8 dB 下 +14.5 pp）承担「鲁棒去噪」职责，前端 ASR/阻抗感知承担「硬伪影剔除」**。

|---|---|---|---|
| **P0 原型（单通道验证）** | 1 个主动电极 + 1 通道 AFE + 数字读出，验证「电极缓冲 → AFE → 解码」信号链 | 与商用脑电（或信号发生器 + 湿电极对照）比对波形/噪声底，测接触阻抗 | 主动电极缓冲的输入阻抗/CMRR 是否达标；干电极高阻抗下噪声底控制 |
| **P1 多通道（8 通道同步）** | ADS1299 8 通道 + 主动电极阵列 + SPI 菊花链，跑通委托人的 8ch 解码 | 用 BCIC 2a/EEGMMIDB 复现精度（对照已有 22ch/8ch 基线），测 8 通道同步性/串扰 | 多通道参考电极/BIAS 设计；通道间串扰与共模抑制 |
| **P2 HBC 组网** | 电极→集线器用 EQS-HBC 互联，替换屏蔽线缆，加阻抗/伪影感知上报 | 验证「经 HBC 传输 vs 直连」解码精度差 ≈0（项目已有 McNemar p 不显著标准），测多节点介质访问 | 多节点 HBC 同步/冲突；运动下信道时变；每电极功耗预算 |
| **P3 量产化** | 单板集成 AFE+HBC+去噪，BOM 优化，国产 AFE 样片对照，可靠性/一致性 | 一致性测试（N 台同规格信噪比/精度波动）、EMC、环境/长时程老化 | 量产一致性（电极-皮肤界面批次差异）；成本压到目标；合规（非诊断级可先不碰注册证，G-3 红线） |

**时间盒建议（推测，非承诺）**：P0 约 1–2 个月（硬件打样迭代）、P1 约 1–2 个月、P2 约 2–3 个月（HBC 组网协议是最大变量）、P3 视商业化资源而定。每阶段设 kill 条件：P0 若「主动电极噪声底 > 湿电极对照 2×」则回退纯 ADS1299 被动方案；P2 若「多节点 HBC 同步三个月不收敛」则先退「有源屏蔽线缆 + 预留 HBC 接口」。

## 7. 技术实现路径建议（结论）

**推荐架构（已确认技术可行性 + 推测整合）**：

```
[主动电极×8]  ──缓冲+阻抗监测──► [ADS1299 8ch AFE] ──SPI──► [RV1106]
      │                (菊花链可扩 16/32ch)                    │
      └──────────── HBC/EQS-HBC 组网（可选替换线缆）◄───────────┘
                                                              │
                                  去噪：LIF-EEG-TCNet（CPU，已验证 50ms）
                                  或 nASR/轻量 CNN（芯片化后走 NPU，待工具链修复）
```

**分阶段执行（对应第 6 节）**：
1. **P0 先验证最不确定的一环——主动电极的「输入缓冲 + 阻抗监测」**。这是整个模组与「普通 ADS1299 采集板」的差异化所在，也是唯一没有现成已验证电路的部分。用单通道 + 信号发生器/湿电极对照，1–2 个月内拿到「主动电极噪声底 vs 被动电极」的真实数据。
2. **P1 复用已验证的 8ch 解码栈**（ADS1299 是项目已支持芯片，SPI 协议已实锤），把精力花在参考电极/BIAS/串扰，不重新发明采集。
3. **P2 用项目现成的 HBC 闭环方法论**（「经 HBC vs 直连」精度差 + McNemar 显著性 + SNR 瀑布曲线）验证组网，多节点介质访问是新问题，优先时分（TDD）方案（项目已有 99% 采集 / 1% 发射的 TDD 模式）。
4. **P3 的护城河不在本模组本身**（HARNESS P2），在「本模组采回来的真实多模态数据 + 疾病机制 + 干预方案」。模组做「成本/集成度门槛」，数据做「护城河」。

**三条诚实的风险/边界**：
- RV1106 NPU 对 EEGNet 类小模型 INT8 失真（argmax 42–58%），去噪/解码当前只能 CPU 或 SNN 换轨，**别把 NPU 当「还差一个旋钮」**。
- 国产 EEG AFE 的 ADS1299 对标款「软硬件兼容」宣传需样片实测背书，公开规格/价格均缺失。
- BOM 全部为估算，唯一确认为 ADS1299/1298 的 TI 官网 1ku 价；量产价与国产替代价需样片询价后才能锁定。
