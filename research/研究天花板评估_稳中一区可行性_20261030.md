# 研究天花板评估 · 稳中一区可行性（2026-10-30 诚实收敛）

> 结论：**当前条件下，这个研究无法「稳中 SCI 一区」。** 真实水平 = 二区稳、一区靠运气。
> 本文档是经过充分探索（多轮实验 + Codex 两轮辩论 + 完整 novelty 核查）后的诚实结论。

---

## 一、所有「发现」的 novelty 核查结果

| 方向 | 死因 |
|---|---|
| teacher 崩（teacher 满标签 < chance → 蒸馏有害）| 常识：below-chance 软标签有害，任何审稿人第一反应「废话」；真空是因为「退化 regime 没人觉得值得写」|
| 符号判据 sign(gain)=sign(teacher−student) | 常识重述：Cho 2019 capacity mismatch / Yuan 2020 弱 teacher 已覆盖 |
| K/R 分解 | Yuan 2020「KD≈LS」的数值化，工程深化非概念突破 |
| 加噪红利暴涨（+16.15）| 「Noise as a Resource for Learning in KD」2021 已有 |
| KD = 去噪 | 「denoising KD」2023-2026 已有多篇 |
| R 转负（label smoothing 低信噪比下有害）| **Lukasik et al. ICML'20「Does LS mitigate label noise?」已有**（"LS amplifies noise, ≈ 注入对称噪声"）|
| R 非单调窗口（中间 σ 转负、两端中性）| σ=1.5 方差不自洽（R −57.5 vs −16.1 单 seed 波动 3.5 倍），效应量不自洽 |

**每一个「发现」都撞上了已发表文献，或者是不稳的方差。** 唯一真空的（below-chance）恰恰是最常识的。

## 二、Codex 三轮补救路的验证结果

| Codex 建议 | 验证结果 |
|---|---|
| 实验一：救方差（N≥10 seed + bootstrap）| σ=1.5 的 R 双 seed 已都负（−57.5/−16.1），符号已稳健，补 seed 边际价值低 |
| 实验二：温度软标签修复（uniform 稀释 → 保留信号）| **被否定**：teacher 软标签（温度软标签 T=4）也翻负（K+R −37.9），只是比均匀 LS（−57.5）好 19pp——「软化」在低信噪下有害，保留 teacher 信号只能缓解、不能修复 |
| 实验三：teacher 可靠度阈值定律 | **阈值就是 chance**（teacher < 20% 时 R 5/5 转负），= teacher 崩的同义反复，无新信息 |

## 三、诚实的完整判断

**没有一个「杀手级」的、双 seed 稳健的、跨数据集的概念级发现。** 这个研究的真实贡献是「低信噪比生理信号下 KD 失效边界的一个系统图景」（符号判据 + K/R + 2×2 相图 + teacher 崩 + R 转负），但每个组成部分要么是常识、要么有前作，组合起来的「图景」撑不起一区。

**根本卡点**：环境锁死第二个独立数据集（PhysioNet 限速 1.5KB/s + HF 被 GFW 阻断），而「单数据集」正是审稿人最狠的一刀——跨任务复现失败（MI 崩不了）、跨数据集做不了。

## 四、唯一能实质提升把握的路（受环境限制）

**第二个独立睡眠数据集复现 teacher 崩 / R 转负**——这是唯一能把「单数据集现象」升级成「系统性规律」的路，但被环境锁死。若用户能提供代理或手动下载（ISRUC / Sleep-EDF ST 系列，仅 ~117MB），这条可以重启。

## 五、诚实的三个可选下一步

1. **突破环境**：用户提供代理 / 手动下载第二个睡眠数据集，重启跨数据集复现。
2. **接受现状**：以「2×2 相图 + teacher 崩 + R 转负」的图景 framing，投二区期刊（如 Biomedical Signal Processing and Control / J Neural Eng），诚实定位。
3. **换研究方向**：放弃「蒸馏失效边界」这条线，回到更根本的 BCI 应用方向。
