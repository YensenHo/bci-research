软标签 softmax(z/T)；T=4.0、α=0.5、100 epoch、双 seed（42/123）。对比口径：唯一变量 = 有无教师软标签。

二框架可复用性验证 · EEGMMIDB（本周核心）

参数化脚本换到第三个数据集，验证红利能否跨数据集复现。

2.1 数据集

EEGMMIDB（PhysioNet 公开脑电运动想象库，跨被试），两个任务作正反对照：2 类（天花板高）与4 类跨被试（天花板低）。

2.4 框架适用边界（四条）

边界 1
红利来源 = teacher 显著强于 student，差距越大红利越大。
边界 2
teacher 能强多少取决于任务精度天花板。
边界 3
teacher 容量匹配数据量，过拟合拖累红利。
边界 4
极低标签（10%）正则化红利跨任务稳定（+1.5~5pp）。
本周最重要结论：同一套协议，teacher 强 → 红利复现；teacher 弱 → 红利消失。框架从「在某个任务上成立」推进到「知道在什么条件下成立」。

三下一步：蒸馏红利的符号判据（sign(teacher−student)）

红利符号由「teacher − student 满标签精度」决定，根因是教师过拟合（容量 vs 数据量），可用过拟合 gap 事前预测。三数据点 + 双 seed + 6 gap 扫描实证。

3.1 核心规律：红利符号 = sign(teacher − student 满标签)
三数据点（30% 标签，3.7× gap）：EEGMMIDB 4类教师弱于学生（36.3% < 38.5%，−2.2pp）→ 红利 −2.78pp（负）；BCIC IV 2a cross教师强（62.15% > 57.47%，+4.68pp）→ +5.56pp（正）；within教师强（+5.1pp）→ +2.58pp（正）。符号由 teacher−student 决定，gap（1×→14×）只调节幅度、不改变符号。
3.2 根因：teacher 弱 = 过拟合（容量 vs 数据量）
同样是跨被试 + 35K 教师，EEGMMIDB（2160 样本少）过拟合 → 教师弱；BCIC IV 2a cross（4608 样本够）不过拟合 → 教师强。形式化：teacher − student = Δbias − Δvariance，教师容量超过「数据量 × 任务固有难度」能支撑的容量时 Δvariance 主导 → 教师弱。gap 曲线呈倒 U：负红利在 3.7×（4倍）最深（−2.78pp），更大 gap 反而减弱。
3.3 两级判据（可操作）
  • 后验判据（精确）：蒸馏前训练 teacher + student 满标签，teacher 强 → 蒸，teacher 弱 → 跳过。
  • 事前 proxy（便宜）：只训练 teacher，看过拟合 gap（train−val）——EEGMMIDB 4类 +34.91pp → 负，cross +24.07pp → 正，within +22.84pp → 正，单调一致。gap 大 → 教师泛化弱 → 预期负红利。
3.4 切入角度：与现有工作的差异
  • 2026 年「蒸馏何时有害」兴起（Strong Teacher Not Needed / Why Robust Teachers Fail / When Does KD Hurt），但都从「教师容量 / 置信度 / 数据」切入，没人给出「sign(teacher−student) 定符号」的精确判据 + 过拟合根因 + 脑电三数据点实证。
  • EEG × 蒸馏现有工作全是用蒸馏解决域泛化/轻量，没人用 EEG 研究「同模态容量蒸馏的符号边界」。
  • 适用范围诚实界定：负红利显著性依赖「高维 + 低信噪比 + 小数据」（脑电典型），合成数据上红利幅度极小、符号不稳。
